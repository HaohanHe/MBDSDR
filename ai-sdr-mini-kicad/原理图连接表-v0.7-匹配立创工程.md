## 三点一、PCB 板层与设计指南

### 板层设置（2 层板）
- 层数：**2 层**（Top + Bottom）
- 板厚：**1.6mm**（默认）
- 铜厚：**1oz（35μm）**（默认）
- 最小线宽/线距：**6mil / 6mil**（嘉立创免费工艺）
- 过孔：内径 **0.3mm** / 外径 **0.6mm**（嘉立创免费工艺）
- 顶层和底层都**铺铜接地**（ground pour），大面积地平面

### 布局建议（约 50mm × 40mm）
| 区域 | 放什么 | 原因 |
|------|--------|------|
| 板子一侧边缘 | J1 Type-C + USB1 USB-A + U1 USB2514B | 都接电脑/扩展，放同一侧方便插线 |
| 对侧边缘 | RF1 SMA + U2 SI4732 | 天线输入，SMA靠边，SI4732紧贴SMA |
| 另一角 | RF2 u.FL + U6 ATGM336H | GPS天线，u.FL靠边，GPS模块紧贴 |
| 中间 | U4 ESP32-S3 模组 | 最大件，放中间，四周走线 |
| ESP32附近 | U5 BMI260 + U3 TMAG5273 | IMU/磁力计测姿态，远离大电流元件，放板子中间 |
| Type-C附近 | U7 AMS1117 + F1 | 电源入口，5V进来先过保险丝再稳压 |
| 各处 | 去耦电容紧贴对应芯片电源脚 | 去耦电容必须离芯片<5mm |

### 走线关键规则
| 信号 | 线宽 | 要求 |
|------|------|------|
| SMA→SI4732 天线 | **1.5-2mm** | 50Ω阻抗线（1.6mm板厚1oz铜），尽量短直，45°角，周围包地多打地过孔 |
| USB D+/D- | **0.2mm** | 差分对，平行等长（误差<5mil），间距0.2mm，少打过孔 |
| 5V 电源 | **0.5-1mm** | 尽量粗，过电流 |
| 3.3V 电源 | **0.5mm** | 尽量粗 |
| I2C/I2S/UART/GPIO | **0.2mm** | 普通信号线，0.2mm够了 |
| u.FL→ATGM336H | **1.5mm** | 50Ω阻抗，尽量短，包地 |

### 射频与地
- SMA到SI4732的FMI/AMI走线**不要打过孔**，全程顶层走
- 射频走线两侧**打地过孔阵列**（间距<5mm），底层对应区域完整地平面
- GPS有源天线馈电：3.3V→L2(100nH)→u.FL中心针，L2旁边放100nF到地（π型滤波，C16可兼用）
- 数字地和模拟地**单点连接**（在AMS1117输出端附近接一起），2层板简单处理全铺地也行
- 晶振X1下方**不要走线**，周围包地，晶振到SI4732 pin13尽量短
- 晶振X2(24MHz)下方**不要走线**，周围包地多打地过孔，晶振到USB2514B pin2/pin3尽量短（<5mm），两个18pF负载电容紧贴晶振引脚

### 丝印
- 板名：**ai-sdr Mini** + 版本号 v1.0 + 日期
- 每个连接器旁边标功能：TYPE-C、USB-A、SMA(ANT)、u.FL(GPS)
- LED旁边标含义：PWR/RX/GPS/AI（虽然全黄，丝印要标清楚）
- 按钮标：RESET
- 呼号：BI4MIB（可选，加个开源项目标识）

## 四、U2 SI4732 连接（SOIC-16，I2S数字输出模式，已按Skyworks数据手册修正）

| SI4732引脚 | 引脚名 | 连接到 | 说明 |
|-----------|--------|--------|------|
| pin1 | LOUT/DFS | U4(ESP32) IO5 | I2S帧时钟 LRCLK |
| pin2 | GPO3/DCLK | U4(ESP32) IO4 | I2S位时钟 BCLK |
| pin3 | GPO2/INTB | U4(ESP32) IO10 | 中断输出（RDS/调谐完成/RSQ） |
| pin4 | GPO1 | NC | 通用输出，空 |
| pin5 | NC | NC | 空脚 |
| pin6 | FMI | 经C4(100nF) → RF1(SMA)中心针 | FM天线输入（隔直电容必须100nF） |
| pin7 | RFGND | GND | **射频地，必须接地，多打地过孔** |
| pin8 | AMI | RF1(SMA)中心针（直连） | AM/SW天线输入（FM/AM共用SMA） |
| pin9 | RST | U4(ESP32) IO11 + R19(4.7k)上拉到3.3V | 复位，低有效，**必须上拉** |
| pin10 | SENB | GND | I2C地址选择，**接地=0x11**（接VDD=0x63） |
| pin11 | SCLK | I2C0_SCL（U4 IO8） | I2C时钟，R5(4.7k)上拉 |
| pin12 | SDIO | I2C0_SDA（U4 IO9） | I2C数据，R6(4.7k)上拉 |
| pin13 | RCLK | X1(32.768kHz晶振)端1 + C1(12pF)到GND | **晶振输入，注意pin13是RCLK不是SCLK** |
| pin14 | VDD | 3.3V，C3(100nF)到GND | 电源（2.7-3.6V），去耦电容紧贴pin14 |
| pin15 | GND | GND | 地 |
| pin16 | ROUT/DOUT | U4(ESP32) IO7 | I2S数据输出（接ESP32 I2S_DIN） |

**X1 32.768kHz晶振接线（单端接法）：** SI4732-A10只有RCLK(pin13)一个时钟脚，晶振接在RCLK与GND之间。原理图用4脚Crystal符号：pin1=RCLK，pin3=晶体另一端=GND，pin2/pin4=金属壳地=GND（即物理3215四脚封装：两个信号脚一个接RCLK、另一个接地，两个地脚接地）；C1(12pF C0G)接在RCLK与GND之间作负载电容。**只需要一个12pF电容**。晶振下方不要走线，周围包地。

**I2S数字输出配置：** SI4732配置为I2S从模式（SI4732输出BCLK/LRCLK/数据，ESP32配置为I2S主接收），16位立体声，48kHz。I2S_OUTPUT_CONFIG属性设置为I2S格式。

**电源去耦：** C3(100nF)必须紧贴pin14(VDD)和pin15(GND)，引线<5mm。

**注意：** 之前版本误将pin13标为SCLK、pin11标为RCLK、pin10标为其他功能，已全部修正。以Skyworks官方数据手册Si4732-A10-short为准。

### 5.7 复位
- EN：接SW1按钮（按下拉低）+ R8(10k)上拉到3.3V

### 5.8 strapping pin说明
- GPIO0：boot模式选择，上电时必须为高（正常启动）。R11(10k)上拉到3.3V，同时可接按钮到GND（下载模式）。
- GPIO3：JTAG源选择，上电时必须为低（默认JTAG）。LED3阴极接IO3，上电时GPIO为高阻，LED不亮，IO3为低，满足要求。
- GPIO45：VDD_SPI电压选择，上电时必须为低。未使用，内部下拉。
- GPIO46：ROM消息输出，上电时必须为低。LED4阴极接IO46，上电时GPIO为高阻，LED不亮，IO46为低，满足要求。

### 5.9 预留GPIO
IO12、IO13、IO14、IO15 预留（云台控制/八木天线切换/未来扩展/IMU中断可选）。

**X2 24MHz晶振接线：** 晶振端1接pin33(XTALIN)，端2接pin32(XTALOUT)；C17(18pF)一端接pin33到GND，C18(18pF)一端接pin32到GND。晶振下方不要走线，周围包地多打地过孔。

**配置引脚说明（复位时采样）：**
- CFG_SEL[1:0] = pin25/pin24 = 00 → 内部默认ROM配置（不需要EEPROM）
- NON_REM[1:0] = pin22/pin28 = 00 → 所有端口可移除
- LOCAL_PWR = pin28 = 0 → 总线供电模式（从USB VBUS取电）

**重要：** USB2514B-AEZC（非BT版本）**必须外接24MHz晶振+CRFILT电容+PLLFILT电容+RBIAS 12kΩ电阻**，缺任何一个Hub都不工作。如果想省掉晶振，可以换成USB2514BT-AEZC（内置晶振版本），但需确认立创有货。

## 十、U3 TMAG5273A1QDBVT 连接（SOT-23-6，TI 3轴磁力计，已按数据手册修正）

| 引脚 | 引脚名 | 连接到 | 说明 |

**I2C地址固定0x35**（7位），写地址0x6A，读地址0x6B。TMAG5273没有ADDR引脚，地址不可通过引脚选择（可通过I2C寄存器修改，但默认0x35）。与SI4732(0x11)、BMI260(0x68)不冲突。

## 十二、U7 AMS1117-3.3 电源（SOT-223，已核对引脚）

| 引脚 | 引脚名 | 连接到 |
|------|--------|--------|
| pin1 | GND | GND |
| pin2 | VOUT | 3.3V_MAIN，C9(10μF)+C10(100nF)到GND |
| pin3 | VIN | 5V_USB，C7(10μF)+C8(100nF)到GND |
| 散热焊盘 | VOUT | 跟pin2连通，接3.3V_MAIN，多打地过孔散热 |

## 十三、RF1 SMA / RF2 u.FL 天线

- **RF1(SMA，直插蝙蝠无线BWSMA-KE-Z001)**：中心针分两路——一路经C4(100nF隔直)到U2 pin6(FMI)，另一路直连U2 pin8(AMI)。U2 pin7(RFGND)直接接地。L1(68nH)可选（AM波段匹配），FM波段不用L1。
- **RF2(u.FL，贴片HMTConn)**：中心针接U6 ANT，3.3V经L2(100nH)馈电（有源GPS天线，L2隔交通直）。C16(100nF)在ANT端到GND滤波。
- 两个连接器外壳均接GND，多打地过孔。
- SMA到SI4732的FMI/AMI走线尽量短（<2cm），包地，阻抗50Ω，下方不要走其他信号线。
- u.FL到ATGM336H ANT走线尽量短，包地，下方完整地平面。
