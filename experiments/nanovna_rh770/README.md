# 实验记录：NanoVNA-H × RH770 双频鞭天线实测

- **日期**：2026-10-23（跨两次会话连续实测）
- **口径**：`recorded`（真机实测）——本文所有数值均来自 NanoVNA-H 实物经串口采集，
  无任何合成信号、无估算冒充。失败案例与误判过程如实记录（见第 4 节）。
- **设备**：NanoVNA-H，固件 1.2.50（STM32F072），USB CDC 115200 8N1，本机端口 COM11
- **被测件**：RH770 双频鞭状天线（2m / 70cm 段）+ 操作者馈线（标签"1 米"，实测电气长度 1.46m）
- **校准件**：空头（OPEN）/ 短头（SHORT）/ 银色 50Ω 头（LOAD），实物标准件

---

## 1. 固件协议实测结论（逆向自实物，非文档抄录）

| 结论 | 细节 |
|---|---|
| `sweep` 即触发器 | `sweep <start> <stop> <pts>` 每发一次出一遍新扫；点数固件锁死 101（请求 201/501 均只回 101） |
| 安全取数链 | `sweep` → 等 **≥1.0s** → `data 0` → 读 101 行。等待不足（0.25s）会读到写了一半的扫描缓冲（race 污染） |
| race 污染诊断法 | 污染特征 = 两段数据尾部**逐位相同**（断点 index ~56–60） |
| 裸 `scan` 禁发 | 裸 `scan` = 持续流模式，会卡死 shell 与屏幕（本实验实际发生一次，`pause` 远活恢复成功） |
| `reset` 禁发 | `reset` = 真重启（本实验误触一次，端口 ClearCommError，等待重连恢复） |
| 设备旧校准 | 固件 config 存旧校准（`cal` 回报 `load isoln Es Er Et cal'ed`，重启不丢）；`data` 返回已校准数据；可被后端 SOLT 精确逆消（E∘C=identity），数学上无害 |
| `capture` 截屏 | 发 `capture\r` → 回显行 → 153600 字节 RGB565 小端裸帧（320×240）→ `ch> ` 尾 4 字节。**USB CDC 实际不理会 115200 波特率，帧约 0.5s 传完**（仓内 `nanovna_client.py` 注释中"约 13.4s"的估算不成立，本次证伪） |

`capture_screen()` 为仓内 `mbdsdr_ai/nanovna_client.py` 代码路径的**首次真机验证**（本次实验完成）。

## 2. 后端 SOLT 校准链 + 一条关键教训

- 三标准件各 24 平均采集（`scripts/vna_capture3.py`），`scripts/vna_cal_any.py` 解 3×3
  误差盒并应用校准；理想定义件 Γ=+1/-1/0，闭式解。定义件失配（空头边缘电容/短头引线电感）
  是固有误差，主要影响相位。
- **教训：手持漂移天线禁用平均采集。** 又深又窄的谐振坑（亚 MHz 级宽）会随触碰漂移
  （实测在 396/404/409MHz 间跳动），24 平均等于把坑抹糊成浅坡——本实验 408MHz/-28dB
  深坑因此未进入 24 平均存档，并直接导致一次"深坑消失"误判（详见第 4 节）。
- 正确测法：**单次扫描 + 细步长（≤0.4MHz）+ 状态锁定 + 操作者稳住不动**。

## 3. 馈线实测

- 电气长度 **1.46m**（段1 全段）/ 1.56m（段2 干净区）交叉印证 → 若真为 1m 物理长度则
  VF=1.46 不可能，**实际约 1.7–2.2m 或标签不准**。
- 双程损耗 0.6–0.85dB@100–200MHz、1.5dB@435MHz（偏大，RG-174 级或老化线）。
  天线回损读数经馈线后被双程损耗压低，相关结论均已注明。

## 4. RH770 测量结果（状态表）

| 状态 | 2m 段（140–160MHz） | 70cm 段（380–455MHz） |
|---|---|---|
| 全展（无地网） | 150MHz / 40.8dB（细扫单扫记录） | 无坑；400→455 由 15dB 单调降至 5dB；435≈6.6dB |
| 误收短（拉杆缩回线圈区） | 150 谐振消失；下半截独振 128MHz（λ/4） | 调谐被毁，300–450 无坑 |
| 全展 + 金属地网（箔片怼 SMA 外壳） | 147MHz / 30.6dB；146MHz 回损 13.4→25.8dB（VSWR 1.11） | — |
| **半拉（操作者指正：408 深坑的正确状态）** | — | **408MHz / -28dB，又深又窄；随触碰漂移 396–409MHz** |
| 全展（次日复查） | 148MHz / 24.8dB（健康） | 380–550 无深坑；425 宽峰 15dB、524 峰 20dB |

- 408/-28dB 数据来自侦察细扫（单扫、细步长），未入 24 平均存档。"深坑消失"误判归因：
  平均抹糊 + 状态不对（全展 vs 半拉）+ 复测步长太粗（0.6–1.7MHz）三重因素叠加，
  由操作者一语点破（"刚才是拉到一半才有那个深坑"）。
- 地网对照实验（操作者方法论纠偏："没有地网不严谨"）证实：无地网时馈线屏蔽层 = 辐射体，
  测的是"鞭 + 屏蔽层 + 室内"系统；补地网后 146MHz 回损 13.4→25.8dB。

## 5. 408MHz 谐振机理（操作者提问"为啥能谐振到 408"）

- 70cm 裸导线 λ/4 单极子谐振只在 ~107MHz；408MHz 需要电气长度 ~18cm（λ/4）——相差 4 倍，
  故底部必有加载线圈/陷波网络做电长度变换。
- 谐振点由 `f = 1/(2π√(LC))` 决定：L = 线圈电感，C = 辐射体分布电容 + 端电容 +
  地网/环境寄生电容；线长只决定辐射电阻与方向图，钉不住谐振频率。
- -28dB 又深又窄（宽几 MHz，Q≈80–100）= 高 Q 电路谐振特征；真实鞭状天线的 λ/4 谐振宽而浅
  （对比 146MHz 地网谐振 25.8dB 宽峰）。
- 漂移机理：高 Q 回路对寄生电容极敏感——手靠近 = 并入几 pF，金属箔片怼 SMA 外壳 =
  改地网回流路径；3% 频移对几 pF 完全正常。操作者观察到的"一动就飘"本身就是该机理的现场演示。

## 6. 406–409MHz 频段事实（国无办 2025-03-01 起施行的 400MHz 对讲机新规划）

| 频段 | 属性 |
|---|---|
| 406.0–406.1MHz | 卫星应急示位信标**专用**（COSPAS-SARSAT/EPIRB/ELT/PLB，地对空；ITU 5.266/5.267 全保护，≤5W） |
| 406.21–407.70MHz | **共用**对讲机（120/240 个同频单工信道，≤5W，免频率许可但要台执照） |
| 409.75–409.99MHz | **公众**对讲机（20/40 个信道，≤0.5W，免许可免执照） |

天线谐振点在"专用/共用/公众"三段间横跳纯属巧合。VNA 只收不发（µW 级激励）无监管问题；
若真发射，406.0–406.1 为受保护禁带。

## 7. 屏幕截图证据

`data/vna_screen_*` 四组（live / detail / wide / 2m），由仓内 `capture_screen()` 采集，
RGB565 小端转换（`scripts/vna_screenshot.py`、`scripts/vna_shot_2m.py`）：

| 文件 | 内容 |
|---|---|
| `vna_screen_live` | 操作现场屏：M1 402.000MHz、S11 -10.08dB、START 250/STOP 450/BW=1000Hz/101p |
| `vna_screen_detail` | 380–440MHz 特写：M1 401.600MHz |
| `vna_screen_wide` | 250–450MHz 全景 |
| `vna_screen_2m` | 100–250MHz：148MHz 谐振深坑清晰可见 |

颜色核验（帧像素分类计数）：黄 `#FF07`（S11 LOGMAG trace）/ 绿 `#1FF8`（S11 SMITH）/
紫 `#E0FF`（S21）/ 红 `#E007`（M1 标记）/ 白 `#FFFF`（文字）/ 黑 `#0000`（底）。
与真机一致；**照片中屏幕的蓝色观感是 LCD 漏光背光，非真蓝色，真实底色为黑**。
屏幕标记点读数与 `data 0` 回读数值互相印证（~-10dB@402），设备校准数据可信。
屏幕上的细深尖峰在点数据中复现不出 = 单扫空口拾 EMI 不稳定性（单扫 |S11| 波动约 3%）。

## 8. 脚本与数据

- `scripts/`（23 个一次性工具）：
  - 协议逆向：`vna_probe` / `vna_help` / `vna_sweeptest` / `vna_timing` / `vna_triggertest` /
    `vna_scansem` / `vna_validate` / `vna_bwtest` / `vna_noise_src`
  - 采集：`vna_capture`（v1，race 缺陷版）/ `vna_capture2` / `vna_capture3`（生产版）
  - 校准与分析：`vna_cal_any` / `vna_analyze` / `vna_cable_analyze` / `vna_rh770_final` / `vna_recon`
  - 截图与复查：`vna_screenshot` / `vna_shot_2m` / `vna_recheck2`
  - 连通性：`vna_conn_check`；应急恢复：`vna_recover` / `vna_recheck`
  - 失败与危险案例（`vna_scansem` 卡死设备、`vna_capture` v1 race、`reset` 误触）如实保留作记录。
- `data/`：11 个 JSON（三标准件、馈线、RH770 四状态 raw + 两份 SOLT 校准版）+
  4 组截图（PNG 1x/2x + RGB565 原始帧 `.rgb`，共 23 个文件）。
- numpy 2.4.6 NEP 50 陷阱：`uint8 数组 * 255 // 31` 会回绕（31→7，整图变全黑 max=8）；
  RGB565→8bit 必须 `.astype(np.uint32)` 中转。`vna_screenshot.py` 已修，`vna_recheck2.py`
  为修正后的重转换/侦察脚本。
