# MBDSDR v2 技术预览版硬件

AI 定义无线电（AI + SDR）技术预览板，服务 PNT / LEO / GPP / RTC / SDR 研究。
设计工具：嘉立创 EDA 专业版（4 层板）。v1（ESP32-S3 + SI4732 仅接收，双层板）见仓库 `ai-sdr-mini-kicad/`。

## 板级规格

- 4 铜层，板尺寸 128.9 × 85.7 mm，457 器件 / 329 网络
- 计算：**XC7Z020（Zynq 7020）芯片直贴** + DDR3L 512 MB（MT41K256M16）+ QSPI Flash
- 射频：**AD9361**，70 MHz–6 GHz（含 FM 段），真 2 收 2 发、56 MHz 瞬时带宽
  - 4 路垂直通孔 SMA 经 TCM1-63AX 巴伦差分引出（RX1/RX2/TX1/TX2）
  - 3 路备用垂直 SMA
- PNT：
  - ATGM336H 北斗/GPS（IPEX 有源天线，+3V3 经 100 nH 馈电）
  - UM980 RTK 双天线（U.FL，PPS，多串口）
- 传感器：BMI260 IMU、TMAG5273 磁力计
- 接口：CH334 四口 USB Hub + 多个 USB-A、RTL8211F 千兆以太网（集成变压器 RJ45）、CH343 USB 串口、多组 2.54 mm 排针

## 验证记录

- 几何精确核查（线段-焊盘半径相交模型）：全部信号网络连通；GND / +3V3 为铺铜网，靠灌铜连通；空名网络为 NC 集合
- 4 个铺铜（顶层 GND、底层 GND、Inner1 GND、Inner2 +3V3）已全部重灌
- Gerber 逐项核验：4 铜层多边形齐全、板框矩形尺寸与实物吻合、钻孔文件完整
- BOM / PnP 行数与器件数一致（457）

## 已知说明

1. EDA 自动化接口的 DRC 对铺铜连通性失明（v1 已用 Gerber 反证制造输出正确）；密 BGA 区存在少量间距告警级几何，嘉立创 3.5 mil 工艺能力可制造，不影响投产。
2. 本版为技术预览（"能上都上"），器件密度高，焊接以 SMT 为主；通孔器件（SMA、排针、按键、网口）优先通孔封装。
3. 许可：硬件设计文档随仓库采用 MIT；外部参考设计仅借鉴思路，按公开标准/数据手册干净室重写。
