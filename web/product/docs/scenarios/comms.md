# 场景 · 通联 / 应急

> 过境窗口、指向与现场降级方案

## 目标

设备条件不稳定时仍要能干活：有执行机构走闭环，没有就固定天线 + 高仰角窗口，没有 SDR 就退到预报与记录计划；站址未校准时拒绝给可信结论。

## 可用的能力组合（真实工具域）

[SDR 调谐/VFO](../wiki/capabilities/sdr-vfo.md)、[书签扫描卫星](../wiki/capabilities/sat-scan.md)、[卫星链路](../wiki/capabilities/sat-link.md)、[系统设备](../wiki/capabilities/system.md)

**能力而非流程**：以上是该场景常用的能力位，不是执行顺序。模型现场问设备，按回答装配任务；
同一个场景在不同现场会长成不同的样子。

## 可出示的证据

内置下行频率表与 TLE 历元、站址可信度状态、写工具人工门回执、降级方案的诚实回执。

## 模型可能调用的工具

模型可能调用 `get_satellite_pass`、`sat_link_tuning`、`set_frequency`；是否存在这些能力由现场提问决定。

## 诚实边界

- 无 TLE / 站址未校准时，不给出可信过境结论；
- 内核未连接时工具返回离线失败回执；
- 规划 / 未验证项逐条留档，不包装成已验证；
- 能力用可复跑命令证明，不用数字标语。
