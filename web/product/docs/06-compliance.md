|---|---|---|
| Stellarium Web Engine（WebGL 天象引擎） | AGPL-3.0 | **只学机制**：地景固定地平系、FOV 缩放、grab-the-sky、加法大气、2s 呼吸指针；不复制源码、不复制贴图、不复制星表 |

## 2. 学到的机制（思想层，可自由复用）

| 机制 | 我们的独立实现 |
|---|---|
| 地景 = 球面全景、无穷远、固定在 OBSERVED 地平系；随 `ro2v` 同矩阵运动 | Canvas 2D 世界坐标高度场 + 树，随相机平移/缩放，不随时间转 |
| 缩放 = 改 FOV，不推拉相机 | `cam.ts` 指数变化 → `scale` 缓动 |
| 拖拽 = grab-the-sky（按下点钉在光标下） | `screenToWorld` 反投影，拖拽全程反补 `cam.tx/ty` |
| zoom-to-cursor | 缩放前后反补视角，光标下天体不动 |
| 选中指针 2D 层逐帧重投影、2 秒呼吸 | `sin(t·π/1000)` 半径抖动 + 4 段十字准星 |
| 大气 = 解析散射 + 加法混合，星空后地景前 | 渐变辉光 + 雾带，`globalCompositeOperation = "lighter"` |
| 放大到贴图极限淡出（`alpha_fov`） | `cam.ts > 2.6` 地景渐隐 |
| 渲染顺序（大气 35 → 地景 40 → 标签 100 → 指针 199） | `drawSky()` 的分层顺序一致 |

## 3. 独有资源不复用

- HiPS 球面地景贴图、星表、Gaia/Hipparcos 数据：本工程用程序化星点与世界坐标高度场替代，**未拷贝任何贴图/星表**。
- 界面文案、图标、布局比例：按 `.figma` 设计语言自行实现。
- Wikipedia 外链只做超链接跳转，不抓取、不内嵌正文。

| 数据 | 来源 | 状态 |

| 卫星编号 / 频段 / 体制 | 公开卫星资料与仓库协议栈口径 | 演示值，非实时 |
| **恒星 RA/Dec / V 星等 / B-V** | **HYG v4.1**（真下载，25,792 颗，J2000） | **真实星表**，CC BY-SA 4.0 署名；见 [10-sky-catalog.md](10-sky-catalog.md) |
| 星座连线 / 中文星官 / DSO | 仓库 `constellations.py` / `dso.py` / `data/*_culture.json` | 常识级对照，端点全部可查 |

## 5. 隐私
