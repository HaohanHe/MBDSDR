# 05 · 设计语言（.figma 唯一视觉依据）

> 来源：`D:/mbdsdr/.figma` 导出的组件稿（jsx + scss module）与 73 张设计图全量提取。任何 UI 产出先对照本表。

## 1. 色板

纯黑画布，**不使用彩色**；层级靠白/灰阶与 opacity。

| 用途 | 值 |
|---|---|
| 画布 | `#000` |
| 大面板 | `#1f1f1f` |
| 次级面板 | `#2c2c2c` |
| 选中 chip | `#606060` |
| 主文字 | `#ffffff` |
| 次级文字 | `rgba(255,255,255,.62)` |
| 三级文字 | `rgba(255,255,255,.32)` |
| 分割线 | `rgba(255,255,255,.12)` / `.24` |
| 方位字（唯一彩色例外） | `#d2542c`（Stellarium 式橙红方位标） |
| 夜视叠加 | `rgba(120,0,0,.42)` |

常用 opacity：`0.3` / `0.23`。灰阶语义：白 = 强调与选中，灰 = 层级，黑 = 底。

## 2. 字体

```css
--sans: MiSans, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", SimHei, Arial, Helvetica, sans-serif;
--mono: "Cascadia Code", Consolas, "Courier New", monospace;
```

- letter-spacing 0（中文）；标签/分组标题用 `.16em ~ .28em` 拉宽做节奏。
- 数字、频率、时钟用等宽字体；正文 13px 左右，分组标题 9.5–11px。

## 3. 圆角体系

| 半径 | 用途 |
|---|---|
| `3px` | 行内 code / 极小元素 |
| `8px` / `10px` / `12px` | 小卡、输入 |
| `13px` | chip、列表项、文档导航项 |
| `24px` | 搜索胶囊、卡片、按钮 |
| `42px` | 大面板（信息卡、抽屉） |
| `84px` | 模式切换、胶囊按钮 |

## 4. 阴影与辉光

- 巨型软阴影：`0 22px 90px rgba(0,0,0,.55), 0 8px 28px rgba(0,0,0,.45)`
- 辉光：`0 0 47px rgba(255,255,255,.10)`；设计稿里还有 blur 19 / 47 / 150px 的多层 `#00000003…1a`
- 浮层：`backdrop-filter: blur(12px~18px)` + 半透明黑底

## 5. 组件口径

| 组件 | 规则 |
|---|---|
| 主按钮 | 白底黑字反转（追踪 / 接收） |
| 次级按钮 | `#2c2c2c` 底、白字 |
| 幽灵按钮 | 透明底 + `var(--line)` 描边 |
| 芯片 chip | 84px 胶囊、`rgba(28,28,28,.7)` 底、1px 描边 |
| 选中态 | 白底黑字 或 `#606060` chip |
| 搜索 | 24px 胶囊，⌕ 图标 + 占位符 |
| 信息卡 | 42px 圆角、`•••` 拖拽手柄、巨型软阴影、噪点纹理 |
| 对话气泡 | 用户 = 白色实心黑字；模型 = `#2c2c2c` 灰面板 |
| 频谱 | 白描边 + 白色渐变填充；瀑布 = 黑→白灰阶热力 |
| 天体标记 | **白点 + 细环**（四级白/灰阶分层），不是彩色图标 |
| 轨迹 / 路线 | **白色圆头粗线**，透明度和仰角对应；轨道弧 = 白色圆头虚线 |
| 传感器 / 锚点 | 白点 + 细环 |
| 方位字 | 橙红点 + 字母，锚在世界方位随镜头走 |

## 6. 布局节奏

- 顶栏 56px，星象仪沉浸态降到 52px、背景更透。
- 星象仪：搜索胶囊顶部居中、信息卡左上、圆形缩放钮卡下、底栏图标工具栏居中、地点 chip 左下、时间 chip 右下。
- 专业模式：三分栏（工具树 / 频谱 / 协作栏）+ 可拖分隔条 + 底部状态栏。
- 抽屉从右滑入；信息卡打开时若 AI 抽屉也开，信息卡让位避免遮挡。

## 7. 动效

- 入场：星点从中心炸开（`burstT` 0→1，约 0.9s）。
- 锁定：镜头缓动飞向卫星（`ease = 1 − 0.0025^dt`），追踪环 2 秒呼吸。
- 面板：`.35s cubic-bezier(.2,.8,.2,1)` 滑入/淡入。
- 夜视、大气辉光为逐帧渲染，不做 CSS 滤镜叠加（保持与天球一致）。
