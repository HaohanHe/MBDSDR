# 02 · 用户指南

## 打开

双击 `dist/index.html`（发布态单文件）或 `index.html`（开发态分层）。无需安装、无需联网、无需服务器。

## 星象仪模式

| 你想做 | 怎么操作 | 会发生什么 |
|---|---|---|
| 看全天空 | 打开页面 | 星点从中心"唰"地炸开铺满全屏；2.4 秒后自动演示锁定 ISS |
| 换一颗星 | 点白点+环标，或在搜索胶囊输入 `METEOR` / `ISS` / `25544` 回车 | 镜头飞过去锁定，信息卡铺开 |
| 看天动星静 | 点底栏 ⏱ 切到 ×300 / ×1800 | 星空绕极旋转、辉光从黄昏变夜；**地景钉死不动** |
| 转视角 | 按住天空拖拽 | 按下点的天体钉在光标下；地景、方位字、轨道弧一起跟手 |
| 缩放 | 滚轮 / 信息卡下 − ＋ 圆钮 | 改 FOV；光标下的星不动；放大到极限时地景淡出防糊 |
| 脱离锁定 | 拖拽、点信息卡 ✕ | 视角原地不动，不弹回中心 |
| 图层 | 底栏图标：轨道线 / 标签 / 银河 / 大气 / 地景 / 网格 / 夜视 / 卫星层 / 时间 / 全屏 | 开关状态持久化 |
| 追踪 / 接收 / 指向 | 信息卡上的三个按钮 | **只是打开对话**；模型现场问设备，按你的回答装配任务 |
| 让模型做某件事 | AI 抽屉底部输入框直接说 | 模型按现场能力组织工具调用；说"定轨"才会走那条链路 |

**摄像机语义**：锁定后卫星钉在画面中心，天在动、星不动；地景随相机走、不随时间走。

## 专业模式

- 顶栏切到「专业模式」：频谱（白色描边 + 渐变填充）、瀑布（灰阶热力）、控制条（中心频率 / 模式 / 带宽 / 增益 / 参考电平 / 解调链）。
- 左栏四组：接收设备、解调协议栈、AI 工具箱、任务场景。工具箱列的是**能力**，不是执行步骤。
- 右侧模型协作栏与星象仪模式共用同一能力核心；输入框里直接说需求。
- 中间与右栏之间的分隔条**可拖**，布局弹性。
- 底部状态栏实时显示能力矩阵在位数量与数据源状态。

## 能力矩阵

左下「◧ 能力矩阵」可折叠：真实工具域可逐个开关、状态持久化；规划未验证项带徽标且不可开启。关掉的位不会被模型当作现场已有设备。**这里是能力位清单，不是流程**：谁先谁后由模型按你的回答决定。

## 语言

顶栏右侧语言钮循环 `中文 → 日本語 → English`：

- 静态界面文案、动态信息卡、对话模板、能力名与描述全部切换；
- 偏好写入 localStorage，下次打开保持；
- 文档中心有**独立**语言钮：文档暂未翻译时显示中文原文并明确标注"暂无该语言译本"，不假装已本地化。

## 文档中心 / Wiki

顶栏 `? 文档`（或侧栏「文档 / Wiki」）打开：左侧按「产品与规格 / 工程与架构 / 能力百科 / 场景 / 参考与术语」分组，右侧渲染全文。每个工具域与每项规划能力各有一页词条，含真实工具清单、调用通道、现状与 not_verified。全部离线内置，不联网。

## 数据诚实口径

- 默认**离线诚实空态**，状态栏显示「未连接 SDR」；`dist/index.html?hub=1` 走 ControlHub 回环 HTTP，
  或由 Qt/WebEngine 注入 `window.mbdsdrBridge`。写工具未确认时显示「人工门未确认（gated · 非失败）」。
- 卫星读数、过境时刻、频谱、瀑布均为演示值；站址默认未校准，信息卡明确提示锁定与过境预报不可用。
- 工具调用在离线时返回失败回执（"离线 · 未伪装成功"），不会显示假成功。

## 键盘与鼠标速查

| 输入 | 行为 |
|---|---|
| 拖拽画布 | grab-the-sky 旋转视角（同时解除锁定） |
| 滚轮 | zoom-to-cursor 缩放 |
| 点击白点 | 锁定卫星并铺开信息 |
| 搜索框回车 | 按编号 / 名称 / 类型 / 别名查找并锁定 |
| 对话输入框回车 | 发送给模型 |
| ⏱ 连点 | ▶ → ×60 → ×300 → ×1800 → ⏸（与桌面端同一套档位） |
