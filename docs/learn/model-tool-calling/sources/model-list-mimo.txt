# §三、Base URL / Key 类型 (来源: mimo-quickstart.txt:21-25)
#   按量付费 OpenAI 兼容:  https://api.xiaomimimo.com/v1            (sk-xxxxx)
#   按量付费 Anthropic 兼容: https://api.xiaomimimo.com/anthropic      (sk-xxxxx)
#   批量推理 OpenAI:        https://batch-api-cn.xiaomimimo.com/v1
#   Token Plan OpenAI:     https://token-plan-cn.xiaomimimo.com/v1   (tp-xxxxx / ttp-xxxxx)
#   Token Plan Anthropic:  https://token-plan-cn.xiaomimimo.com/anthropic
#   → 全部 5 个文本模型同时支持 OpenAI 兼容协议与 Anthropic 兼容协议 (双协议)。

# §四、关键字段边界 (来源: mimo-openai-api.txt)
#   - model 可选值 (原文 §model string 必选):
#       mimo-v2.6-flash, mimo-v2.6-pro, mimo-v2.6-pro-ultraspeed, mimo-v2.5-pro, mimo-v2.5
#   - thinking: {type: "enabled"|"disabled"}, 默认 enabled (全部 5 个文本模型)
#       思考模式下 temperature 强制 1.0、top_p 强制 0.95 (自定义值被忽略)
#   - tool_choice: 仅 "auto" 生效；传非 auto 值后端会移除该字段，行为等同 auto
#   - tools.function.name: [a-zA-Z0-9_-], 最大 64 字符
#   - tools.function.strict: boolean, 默认 false
#   - max_completion_tokens: v2.6 全系/v2.5-pro 默认 131072, v2.5 默认 32768; 范围 [1,131072]
#     (注意: 该值 = 可见输出 + 推理 token 总数上限)
#   - arguments 不保证合法 JSON，可能虚构 schema 外参数 (原文警告, mimo-openai-api.txt:88-89)
#   - reasoning_content 缺失 → API 返回 400 (mimo-reasoning.txt:41-43)
#   - finish_reason: stop / length / tool_calls / content_filter / repetition_truncation
