## 复核须知

- 源码基准是同一份 tarball：`QGIS-final-3_44_15.tar.gz`（版本 3.44.15）。
- 三份文档写作时用了**三个不同的临时解包目录**，`file:///` 链接指向
  `%TEMP%\qgis344`、`D:\qgis-src-34415` 等临时位置；这些目录清理后链接会失效，
  **行号仍可按同一 tarball 重新展开后复核**。引用一律以「源码相对路径 +
  符号名」为准，不要依赖绝对路径。
- 文中「实测」只证明公式级差异（临时脚本不 import 产品代码），
  **未编译、未运行 QGIS**；若要当运行时缺陷证据，必须在真实链路上复测。
- 对 MBDSDR 的落地结论与后续修正见仓库外
  `D:/mbdsdr/output/learn/qgis-3.44.15-复核式学习-2026-11-14.md`。
