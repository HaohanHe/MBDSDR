# Phase51 块1：接收链全场景健壮性实验

> 云内合成 CCSDS/BPSK 链路（`synthesize_ssdv_ccsds_iq` + `ccsds_iq_to_result`，
> 盲 CFO 平方环 + Gardner 眼心 seed），注入真实退化场景，固定种子（seed=5101）。
> 复跑：`python3 mbdsdr_ai/tests/exp_phase51_robustness.py`；回归断言见
> `mbdsdr_ai/tests/test_phase51_robustness.py`。
> 基线参数 FS=48000, SYMRATE=4800（10 sps），48×48 图，frame_bits=8172，2 RS 块。

## 结果总览

|---|---|---|---|---|---|

| (a) 弱信号 sd=1.6~3.0 | 同上 | 0 | — | 0/0 | **失效阈值 sd≈1.3~1.6** |

## 各场景说明

### (a) 弱信号 SNR 梯度
- sd=0.3/0.5/0.8/1.0/1.3 全部 36/36 MCU、RS nerrors=0；
- **sd=1.6 起 ASM 不同步**（失效阈值落在 1.3~1.6 之间）。
- 该阈值是本 48×48 短帧 + 2 次重复 RS 的合成值；真机长图/低码率下阈值不同，
  现场以 `ASM 同步 N 帧` 与 `RS nerrors` 为准。

### (b) 突发遮挡
- 对照 clean|clean 可出 2 帧；但中段插入整帧遮挡噪声后 → 0 帧。
- **原因（诚实）**：ASM 成帧器在单缓冲内持有状态，第一帧 ASM 后连续收集
  frame_bits，遮挡段把比特流打乱，后续干净段无法重新对齐 ASM。
- **不保证**：当前单缓冲实现**不具备遮挡后逐帧自动重同步**。真机若卫星重复发射
  同一帧，需按帧切窗/多缓冲逐段喂入才能利用重发。

### (c) 多普勒扫频
- 恒定 CFO=100Hz：盲估 100.0Hz，全图正常。
- 整段线性扫 0→200Hz：盲 CFO 估到中点 ~99.4Hz（谱线因扫频展宽，prominence 仅
  ~15），ASM=0。
- **不保证**：整段单峰盲 CFO **只能锁定近似恒定频偏**；对持续多普勒扫频需要
  分段 AFC 或锁相环跟踪，当前未实现。

### (d) 窄带 CW 干扰
- CW amp≤0.3（相对信号幅度）仍全图；amp=0.8 起 ASM=0。
- amp≥1.5 时 +600Hz CW 压过信号，盲 CFO 平方环在 CW 二倍频处取峰 → **把 CW 本身
  当信号估计到 +600Hz**，整链失败。
- **不保证**：盲 CFO 在 ±2·fsym 搜索窗内对强单音无抗干扰能力；需加窄带 notch /
  干扰检测，当前未实现。

## 诚实空态
所有失效场景均 0 帧/0 包/0 字节 JPEG，**不伪造图**。

## 未解决
- 遮挡后逐帧重同步（多缓冲切窗）；
- 扫频跟踪（分段 AFC/锁相环）；
- CW notch 抗干扰；
- 真机过境 IQ 未验证。
