# Phase52：接收链真机级健壮性升级

> 把 Phase51 实测的三个"未实现"补齐：分段 AFC 多普勒跟踪、CW 对消、多缓冲重同步。
> 全部云内合成、固定种子。复跑见 `mbdsdr_ai/tests/test_phase52_upgrades.py`。

## 三块机制

### 块1 分段 AFC（`ssdv_phy.py afc_correct`）
- 滑窗（默认 8192 样本 ≈ 5.9Hz 分辨率）内平方环估频偏；
- **限幅**（|Δf|≤40Hz/窗）防野点；窗内 prominence 不足时**冻结**前值（不跳 0）；
- 窗中心平滑频偏 → 逐样本积分成相位 → 逆旋；estimate_cfo_bpsk 加抛物线亚-bin 精峰。

**实测**：
- 恒定 CFO=100Hz（单估平方环舒适区）：盲估 99.95Hz，36/36 MCU（回归不回退）。
- 线性扫 0→200Hz / 1.74s：无 AFC → ASM=0；有 AFC → ASM=1、部分 MCU（~21/36）。
- **仍失效边界（诚实）**：陡斜率（0→200Hz over 短帧）无法满恢复——AFC 窗分辨率与
  跟踪带宽固有矛盾（小窗快跟但分辨率差、大窗分辨率好但滞后）。满 36/36 对快扫不保证。

### 块2 CW 对消（`ssdv_phy.py notch_cw`）
- FFT 找窄带强峰（bin 幅度 > 局部 ±16bin 均值 × gate=6）；
- 抛物线 + 0.05Hz 细网格精调 CW 频 → 估计复幅度 → **时域参数相减**（非频域切除，
  避免 sinc 旁瓣残留）；
- 信号主瓣宽带、局部均值同高 → 不会被误陷（no-CW 测试 36/36 不误伤）。

**实测**（@+600Hz，seed 5101）：
- amp ≤ 6：无 notch 也能解（Phase52 抛物线 CFO 更鲁棒）；
- amp = 3：notch 后 36/36；
- **amp ≥ 20：notch 也救不回（信号被淹没），诚实 0 帧。**

### 块3 多缓冲重同步（`ccsds_ssdv.py _demod_resync`）
- 按窗 prominence 判信号存在性，遮挡/静默窗丢弃；
- 相邻活跃窗合并成段，每段独立重跑 demod（gardner 重新 seed，不被噪声段带偏）；
- 各段比特顺序拼接，下游 ASM 重搜。

**实测** clean|噪声遮挡|clean：
- 无 resync → 0 帧（被遮挡段带偏）；
- 有 resync → ASM=1，RS 纠 4 符号，36/36 MCU 恢复。

## 仍失效边界清单
1. 陡多普勒扫频（0→200Hz/帧量级）无法满恢复——需更细分段 AFC/锁相环；
2. 超强 CW（amp≥20 @ 带内）淹没信号，notch 不救；
3. 遮挡段过长（活跃段凑不满 frame_bits）仍不恢复；
4. 真机过境 IQ 未验证。
