## 5. 低轨多普勒说明（接收必读）

- 低轨卫星（LEO）过境时相对地面站有径向速度，接收频率会被**多普勒**平移：
  - **AOS（卫星刚升起、接近你）**：接收频率 **偏高**（fd > 0，实测约 +2~3 kHz @2m）；
  - **中天（仰角最高）**：径向速度≈0，fd≈0；
  - **LOS（卫星落下、远离你）**：接收频率 **偏低**（fd < 0，约 −2~3 kHz @2m）。
- 频率越高，多普勒越大：70 cm（435 MHz）的峰偏约是 2 m（145 MHz）的 **3 倍**。
- **FM SSTV 建议开多普勒补偿**：SSTV 是 FM 语音信道，几十 kHz 带宽本身较宽，手动
  跟频通常能收；但过境中段多普勒变化快，**开 NCO 补偿能显著提升出图完整度**。
  对接方式见 `P3-receive-guide.md` 第 4 步与 `mbdsdr_ai/doppler_compensation.py`
  （`remove_doppler_shift`，可吃 `compute_doppler_curve` 的逐时刻频移）。
- SSDV 数字链路对频偏更敏感，建议同样开补偿，并配合 AFC 跟频。
