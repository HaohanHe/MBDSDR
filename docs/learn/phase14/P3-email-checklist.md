# P3 邮件清单：接收成功后换证书

> 收到并解出 SSTV/SSDV 图像后，把材料发邮件到 **CASC70@asesspace.com** 兑换参与证书。
> 下面是发送前逐项核对清单 + 可直接套用的邮件模板。**如实填写，不伪造接收证据**。

## 1. 发送前逐项核对（勾选清单）

- [ ] **姓名**：本人真实姓名
- [ ] **单位 / 学校**：所在单位或学校（无则填「个人」）
- [ ] **业余无线电台呼号**：本人合法呼号（如主办方允许非会员参与，按公告注明）
- [ ] **接收 UTC 时间**：该图成功接收的 UTC（抄 `pass_predict.py` 或 SigMF meta 的
      `core:datetime`；**记 UTC，不要写北京时间**）
- [ ] **接收地点经纬度**：十进制度（如 43.81°N, 125.32°E）+ 城市名
- [ ] **接收设备**：SDR 型号（如 RTL-SDR / RTL2832U）+ 采样率/增益
- [ ] **天线**：天线类型与波段（如 2m 八木 / 70cm 棒状）
- [ ] **接收截图**：接收瞬间的频谱/瀑布或软件截图（能看到信号与时间）
- [ ] **图像附件**：成功解出的 SSTV/SSDV 图像 PNG（**必须成功解码、清晰完整**）
- [ ] **卫星与制式**：是 JAMX01 还是 ASRTU-1，是 SSTV 还是 SSDV
- [ ] 累计已收幅数（活动共 34 幅，按需申报自己收到的幅数）

> 每收到一幅图，建议单独或汇总一封邮件申报；一幅图对应一条接收记录。

## 2. 邮件模板（直接复制填写）

**收件人**：`CASC70@asesspace.com`

**主题**：
```
【业余无线电图像通联】接收申报 - <呼号> - <姓名> - <卫星名>
```

**正文**：
```
组委会老师好：

我报名参加「航天七十载·星火传未来」业余无线电图像通联活动，
现将成功接收的图像申报如下：

  姓名：<你的姓名>
  单位/学校：<你的单位或学校>
  业余电台呼号：<你的呼号>
  接收日期：<YYYY-MM-DD>
  接收 UTC 时间：<HH:MM:SS>Z（以 SigMF/pass_predict 记录为准）
  接收地点：<城市>，纬度 <__.____>°，经度 <___.____>°
  接收卫星：<JAMX01 静安梦想星 / ASRTU-1 阿斯图友谊号>
  图像制式：<SSTV / SSDV>
  下行频率：<官方公布的下行频率，单位 MHz>
  接收设备：<如 RTL-SDR (RTL2832U)，采样率 250ksps，增益 24dB>
  接收天线：<如 2m 八木 / 70cm 棒状天线>
  本次接收信号最大仰角：<约 __°>

随附件奉上：
  1. 成功解码的图像（PNG）；
  2. 接收时的频谱/瀑布截图（含时间与频率）。

我已累计接收 <n> / 34 幅图像。烦请登记并寄送电子证书，谢谢！

顺祝 活动圆满成功！

                                  <你的姓名>
                                  <呼号>  <联系邮箱>
```

**附件**：成功解码的图像 PNG + 接收截图。

## 3. 备注

- 频率/TLE 若当时未由官方公布稳定值，按**实际对准频率**填写即可，不编造。
- 时间一律 UTC；地点经纬度用实际接收位置，不要套用本示例的长春坐标。
- 无呼号者请按主办方公告确认申报身份，不冒用他人呼号。
- 本模板不含任何密钥/敏感信息；正式发送前再核对一遍附件是否齐全。
