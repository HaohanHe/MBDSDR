## 1. 能力链路（每一步一个积木，模型可现场编排）

| 步 | 积木 | 输入 | 输出 |
|---|---|---|---|
| 1 | `sat_rx_profile` | 卫星名 | 下行频率、协议、轨道类型、指向要求 |
| 2 | `doppler_from_frequency` | 观测频率 + 中心频率 | 伪距率 (m/s)、频移 (Hz) |
| 3 | `calibrate_time_offset` | 观测序列 + 接收机 ECEF + 中心频率 + TLE | 时间偏差 (s)、速率偏置 (m/s)、去偏 RMS (m/s) |
| 4 | `tle_state_ecef` | TLE + 历元 | 7 维初值 [r(m), v(m/s), 钟差项] |
| 5 | `doppler_orbit_determine` | 观测 + 站址 + 初值 | 轨道估计 + 残差统计 + 后验协方差 |

> 单位口径（全链统一）：位置 **km**、速度 **km/s**、伪距率 **km/s**；
> 对外字段仍报 m/s（`range_rate_mps` / `rate_bias_mps` / `centered_rms_mps`）。
> 第 7 维是**速率偏置 (km/s)**，模型里直接相加（不乘光速）。

## 2. 材料数据集上的实测（IRIDIUM 107，1626.270833 MHz）

数据集：41 个有效观测（时间间隔 ≥ 5 s），材料记录的观测时间错位约 **15.5 s**。

| 项 | 实测 | 说明 |
|---|---|---|
| 校时 | 找回 **15.5 s** | 与材料记录一致（容差 ±0.6 s） |
| 去偏残差 RMS | 11.9 m/s | 该数据集自身的观测散布 |
| 定轨残差 RMS | 21–43 m/s（随估计器） | 处于 O(10 m/s) 量级，非发散 |
| 轨道半径/速度 | 7107–7142 km / 7.4 km/s | LEO 物理区间，越界即报错 |
| 与 TLE 真值位置差 | 数百 km 量级 | 见 §4 可观测性说明 |

## 3. 施工中查出并修掉的缺陷（都是真 bug，不是调参）

| # | 缺陷 | 症状 | 修法 |
|---|---|---|---|
| 1 | **ECEF 旋转系里直接积分二体**（漏离心/科里奥利项） | 传播 600 s 与 TLE 真值差 **1388 km / 4601 m/s** | 改为 ECI 口径积分再转回（`orbit_dynamics.propagate_state_and_stm`），全仓只留一份传播器 |
| 2 | **两套单位制并存** | `orbit_determination` 用 km/km/s，`orbit_dynamics` 用 m/m/s，校时结果跨制传给估计器 → 偏置差 **1000 倍** | 全链统一 km/km/s；`tle_state_ecef` 不再 ×1e3 |
| 3 | **观测噪声单位错配** | `r_sigma` 按 km/s 传而残差是 m/s → 增益大 1000 倍 → 发散 | `r_sigma` 与残差同量纲 |
| 4 | **第 7 维语义两样** | 一处当"钟差×c"、一处当"速率偏置" | 统一为速率偏置 (km/s)，模型直接相加 |
| 5 | **`rx_alt` 单位错配** | 工具给 m，`geodetic_to_ecef` 要 km | 入口统一换算 |
| 6 | **法方程病态** | `np.linalg.solve` 在 1e9 条件数上爆（位置/钟差近共线） | 改堆叠加权系统的 `lstsq` |
| 7 | **估计器无物理护栏** | 发散时返回离谱轨道 | 加轨道合理性校验（半径/速度/有限性），越界即诚实报错 |
| 8 | **不确定性被吞掉** | 输出只有状态，没有不确定度 | 输出补后验协方差（弱可观测方向的不确定度显式可见） |

## 4. 物理边界（做不到的部分，如实写清）

**单站纯多普勒对位置弱可观**：观测只约束视线方向的速度，"沿轨位置"与"钟差"在短弧上
近乎共线，无法分离。因此：

- 位置改正天然受限：10 Hz 噪声 + 30 分钟弧段下，位置精度在**公里到几十公里**量级，
  **达不到亚公里**；
- 收敛的正确签名是**后验协方差单调下降**，不是"位置误差归零"；
- 想真正定轨，需要多站、GPS 测距、或更长的弧段/更多几何。

**钟差怎么处理**：推荐工作流是"先 `calibrate_time_offset` 校时拿到偏置 → 写进初值第 7 维
→ 固定钟差（`fix_clock=true`，默认）再估轨道"。若让钟差自由估计（`fix_clock=false`），
创新量里的钟差会被摊到速度上，位置预测发散——**这不是实现问题，是可观性问题**。

## 5. 自检（任何人可复现）

```bash
# 材料数据集锚定测试（校时/单位/传播/估计/护栏 共 7 项）
python -m pytest tests/test_orbit_material_dataset.py -q

# 轨道动力学与估计器既有测试
python -m pytest tests/test_orbit_dynamics.py tests/test_orbit_determination.py -q
```

两个关键护栏值得单独说：

- **传播器自洽**：把 TLE 状态传播 600 s，必须与 TLE 真值一致（< 5 km）。
  这条护栏此前**根本不存在**——正因如此，缺陷 #1 才长期潜伏（600 s 差 1388 km 却全绿）。
- **单位自洽**：频偏↔伪距率换算与观测模型同量纲；把状态整体放大 1000 倍，
  预测率必须同比例放大（齐次性）。这条护栏此前也不存在——缺陷 #2 因此无感。
