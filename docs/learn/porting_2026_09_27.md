## 1. SDRangel — Costas 环与信道化

### 1.1 Costas 环（移植到 `coarse_sync.py`）

- 环结构（二阶临界阻尼）：`sdrbase/dsp/costasloop.cpp:51-57`
  - `damping = sqrt(2)/2`；`denom = 1 + 2*damping*BW + BW^2`
  - `alpha = 4*damping*BW/denom`；`beta = 4*BW^2/denom`
- 环路滤波：`sdrbase/dsp/costasloop.h:62-66`
  - `m_freq  += beta * error`
  - `m_phase += m_freq + alpha * error`
- NCO：`costasloop.cpp:85` — `nco = exp(-j*phase)`，与输入复数相乘。
- 相位鉴别器：
  - BPSK：`costasloop.h:86-89` — `e = re*im`
  - QPSK：`costasloop.h:91-95` — `e = sign(re)*im - sign(im)*re`
  - 8PSK：`costasloop.h:97-110` — `K = sqrt(2)-1`，按 |re| vs |im| 分支
- 误差限幅：`costasloop.cpp:104` — `branchlessClip(e, 1.0)`。

### 1.2 信道化器（对照参考，不直接移植）

- `sdrbase/dsp/downchannelizer.cpp:47-90` — 逐样本过多级 halfband 抽取链；
  `:136` 输出采样率 = 基带率 / `2^(stages)`；`:132-134` 用目标通带
  `[req_fc - req_bw/2, req_fc + req_bw/2]` 选 NCO 旋转中心。
- `sdrbase/dsp/fftfilt.h:38-80` — overlap-save 频域滤波：
  `filter[]` 频域乘、`ovlbuf` 保留重叠段、`pass` 分块输出。

### 1.3 FIFO 同步

- `sdrbase/dsp/samplesinkfifo.cpp:26-44` — `create()` 环形缓冲：
  `m_head/m_tail/m_fill`；`reset()` 在锁内清空。对应我们流式
  `feed()` 的有界缓冲思路。

## 2. OpenWebRX — WebSpectra 瀑布与远程解码

### 2.1 FFT 链（移植到 `webspectra.py`）

- `csdr/chain/fft.py:25-49` — `FftChain = [Fft, FftAverager, FftSwap, (FftAdpcm)]`
  - `:20` 无平均时用 `LogPower(add_db=-70)`；有平均时 `LogAveragePower`
  - `:36` `FftSwap` 把 DC 放到中间（等价 `fftshift`）
  - `:43-45` 可选 `FftAdpcm` 压缩
- 块大小：`:78-85` — `block = samp_rate / fps / fft_averages`。

### 2.2 二进制帧首字节（移植到 `webspectra.py`）

- `owrx/connection.py:372-376`
  - `write_spectrum_data` → `bytes([0x01]) + data`
  - `write_dsp_data`（音频）→ `bytes([0x02]) + data`
- `owrx/connection.py:378-379` HD 音频 `0x04`；`:395-396` 副 FFT `0x03`。
- 我们已有 `mbdsdr_ai/web/streamer.py:40-44` 沿用同一首字节约定；
  新 `webspectra.py` 做独立可测的编/解码模块（不依赖 Web/线程）。

### 2.3 ADPCM

- `FftAdpcm` 在 `pycsdr`（C 扩展），Python 侧无源码。我们按 IMA/DVI
  4-bit ADPCM 标准步长表实现（确定性，便于单测），峰值保留降采样沿用
  `streamer.py:157-169` 的块内 max 思路。

## 3. URH — 三层协议分析

### 3.1 第一层：自动解调

- `src/urh/ainterpretation/AutoInterpretation.py:151-207` `detect_modulation`
  - `:157-158` 近零样本占比高 → OOK
  - `:161-165` Haar CWT：`|z|` 与 `|z|/|z|` 分别取小波
  - `:183-186` `var_mag > 1.5*var_norm_mag` → ASK
  - `:189-190` `var_mag > 10*var_filtered_mag` → PSK
  - `:194-206` FFT 双峰 → FSK
- `:373-440` `estimate()`：噪声门限 → 消息分段 → 解调 → plateau 长度直方图
  → 估计 `bit_length`（samples/symbol）。
- `:344-370` `get_bit_length_from_plateau_lengths` — 阈值除数直方图，
  取最小众数（避免 2×/3× 倍频误判）。

### 3.2 第二层：帧同步 / 第三层：协议解析

- `src/urh/signalprocessing/ProtocolAnalyzer.py` — 把比特流切成消息、
  按字段类型打标签。
- `src/urh/awre/engines/LengthEngine.py` — 长度字段公共范围聚类。
- `src/urh/awre/engines/ChecksumEngine.py:36-80` — CRC 多项式/初值猜测。
- 我们已有 `mbdsdr_ai/analysis/protocol_parser.py:51-66` 实现 CRC-16/CCITT、
  `:198-244` 自动同步字检测。新 `protocol_analyzer.py` 把
  modulation_classifier → clock_recovery → protocol_parser 串成三层一体。

## 4. SatDump — 前向纠错与 METEOR LRPT 链

### 4.1 Reed-Solomon

- `src-core/common/codings/reedsolomon/reedsolomon.h:12-16`
  - `RS223` = RS(255,223)，32 校验字节，可纠 16 字节错误（CCSDS TM）
  - `RS239` = RS(255,239)
- `reedsolomon.h:33-36` — `decode/encode(data, ccsds)`；`ccsds=true` 时做
  符号反转（0↔255）以匹配 CCSDS 惯例。

### 4.2 扰码

- `src-core/common/codings/randomization.cpp:4-36` — `ccsds_pn[255]` 字节表，
  首字节 `0xff`，周期 255 字节。扰码 = 数据 XOR 循环 PN。
  （对应 LFSR 多项式 x^8+x^7+x^5+x^3+1，初值全 1；任务书指定 0xA9
   为反馈掩码，我们用查表法保证与上游逐字节一致。）

### 4.3 差分编码

- `src-core/common/codings/differential/qpsk_diff.cpp:5-56` — QPSK 差分：
  相邻符号的 I/Q 异或；`:30-41` 按象限旋转选择输出映射。
- 我们的 `DifferentialEncoder` 做更通用的 DBPSK/DQPSK 差分校调。

### 4.4 METEOR LRPT 链

- `plugins/meteor_support/meteor/module_meteor_lrpt_decoder.cpp`
  - `:34` Viterbi r=1/2 K=7，`phases` 四相互搜
  - `:35` BPSK CCSDS deframer
  - `:119` `ReedSolomon(RS223)`
  - `:172` `diff.decode_bits`（NRZ-M）
  - `:201` QPSK 同步字：差分解 `0xfc4ef4fd0cc2df89`，非差分 `0xfca2b63db00d9794`
  - `:235` `viterbi->work()` 软判决输入
- 我们的 `satellite/meteor_lrpt.py` 做：QPSK 硬判决 → 差分/解扰 →
  RS(255,223) 解码 → 帧重组（Viterbi 留软判决接口，不强行实现 K=7 全译码器）。
