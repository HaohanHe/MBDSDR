## 一、项目学习结论（30 秒版）

**MBDSDR = AI 定义无线电**：把 SDR/VNA 的每个动作封装为 LLM 可调用工具（MCP 协议），外部 agent 遥控真实硬件。三端 + 实验管线：

| 组件 | 位置 | 说明 |
|---|---|---|
| 原生桌面端 | `cpp/` | C++/Qt6，UI 与 DSP 同进程，**主推端**（本次重点） |
| 手机端 | `mobile/` | Flutter，rtl_tcp 直连外置 SDR |
| Python 内核 | `mbdsdr_ai/` | 工具面 + 工作流引擎 + MCP server |
| 论文实验 | `experiments/` | 固定种子可复现 |

**仓库价值观（AGENTS.md，本次修复全程遵守）**：
1. 诚实文化 —— 无硬件/无信号必须显式空态，**绝不 mock、绝不伪造数据**；
2. 死参数、文档与实现不一致 = bug；
3. 布局模型唯一事实源在 C++ renderer；
4. 写动作必须过 `arm_manual` 人工门；
5. 测试期望与常量成对更新，不许删断言变绿。

**C++ 端 UI 结构**：`main_window.cpp` 7901 行（构造函数占 47%），`spectrum_display.cpp` 频谱/瀑布核心交互，设计令牌集中在 `core/tokens.h`。

## 三、ctest 基线 → 修复后

| 阶段 | 结果 |
|---|---|
| 修复前基线 | **155/158**（3 失败：spectrum_display ×3、spectrum_autorange ×2、ui_integration ×1） |
| 修复后 | **158/158 全绿**（e2e_smoke 无硬件诚实 SKIP） |

### 失败根因（全部定位到行级）

1. **`kDefaultSpecFraction` 0.5 → 0.25 未同步测试**（phase82 研究文档明确 25% 瀑布主导，对齐 SDR++ 35%/gqrx）→ 更新 3 个断言与设计 token 成对，语义从「1:1」改为「跟随设计 token + trace 不低于最小可用高度」。
2. **布局顺序变更未同步**：当前为 trace→瀑布→频率轴（频率轴移到最底），测试仍断言频率轴在中间 → 修正断言。
3. **autorange 只动 ceiling 不动 floor**（设计注释明确"floor is the stable manual reference" = -130），测试期望 -100 → 更新为 -130 并注释设计不变式。
4. **`realFrameDrivesHistory` 造数与显示 floor 不匹配**：噪底改用 -130（色图 index 0 = 纯黑），保留 `<50` 断言强度。
5. **测试间状态泄漏**：`quickTune` 用例的 hint 不可见，二分定位污染源为 `tuneHistoryEmptyStateLoadsAndJumps`——见下节真 bug。

## 四、真实缺陷修复（用户可感知，全部已实施 + 测试通过）

### 🔴 P0 —— `currentHiddenLeftPanels()` 误判（视觉证据确凿）
窗口未显示时所有左栏分组 `isVisible()==false`，析构保存时被当成「用户隐藏了全部面板」持久化 → **下次启动左栏整块消失**。
- **修复**：`currentHiddenLeftPanels()` 增加 `window()->isVisible()` 守卫。
- **证据**：修复前 `ui_testsig.png`（左栏空白）vs 修复后 `ui_after_testsig.png`（左栏正常）。

### 🔴 P0 —— `static bool muted` 进程级共享（main_window.cpp:3628）
空格静音状态存函数级 static，第二个窗口按空格方向反转。改为成员 `muted_`。

### 🔴 P0 —— 选中 QPSK/BPSK VFO 抢走右栏标签页（main_window.cpp:4631）
任何 vfoListChanged（增删改/切换选中）都强制把右栏拽到星座页。改为**仅当所选 VFO 真正变化**时才显示星座页（保留用户意图，消除干扰）。

### 🔴 P0 —— 裸 `QSettings s`（main_window.cpp:6686）
「记住上次选中的卫星」读取端用裸 QSettings（落点与写入端 AppSettings 不同 + 绕过测试隔离）→ 永不生效。改用 `mbdsdr::core::AppSettings`。

### 🟠 P1 —— 双 FT8 / 双 Tuner AGC 控件互不同步
「接收参数」与「工具」两个 FT8 勾选框各说各话、后者不落盘；Tuner AGC 同样两处。双向镜像同步（QSignalBlocker 防回环），恢复时同步第二个入口。

### 🟠 P1 —— `bookmarkManager_` / `activityLog_` 内存泄漏
无父对象且析构漏删，每开一个窗口漏一次。析构补 delete。

### 🟠 P1 —— `vfo/count` 恢复无上界钳制
配置损坏可致无上限 `vfoAdd()` 循环（引擎层无 VFO 上限）。`std::clamp(1, 16)`。

### 🟠 P1 —— 快速调谐错误提示不可见（诚实红线）
输入非法频率时错误 hint 被隐藏的祖先面板吞掉 —— 表层是测试脆弱，根因是 hiddenLeftPanels 误持久化（同 P0-1），已一并解决。

### 🟠 频谱交互手感（spectrum_display.cpp）
1. **`grabMouse()` 缺失**：拖拽出画布后释放丢失事件 → 拖拽状态永久卡死，不按键移动鼠标也会继续改频率/拖 VFO 框。加 capture/release 包装 + leaveEvent 兜底。
2. **光标零反馈**：全文件无 setCursor。新增悬停区域→光标映射（分隔带 SplitVCursor、VFO 边 SizeHorCursor、频带 OpenHand、数据区 Cross、拖拽中 ClosedHand），仅在形状变化时写。
3. **带外悬停读数伪造**（诚实红线）：clamp 到边沿 bin，用真实电平标注未采集的频率。改为显式「带外（未采集）」，不带电平/SNR。
