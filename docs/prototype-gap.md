## 3. 两条主线的判断（原型有出入时以本仓为准）

1. **星象仪以时空为主导：星固定，动的是视场与时间。**
   - 本仓 `view_state` 只改中心 az/alt 与 FOV，不改恒星 J2000 坐标；卫星/日月走同一 TimeEngine。
   - 原型用「演示起始时刻 + 离线倍率」推进（L1999、L2160-2167），这是演示，不作为时间基准；本仓拒绝照抄。
   - 因此批 1 优先补 B8/B9 两个时空读数，而不是补入场动画（B7）。

2. **SDR 以频谱为主导。**
   - 原型天空形态完全看不到频谱（只有专业模式有，且是演示参数）；本仓星象仪模式保留底部瀑布槽。
   - 判定：**E2 已达标且比原型强**；不照抄「天空形态无频谱」的分离式布局。
   - 原型专业模式的频谱/瀑布是演示值（L579），不作为验收基线（§4 第 3 条）。

3. **原型更强的项不强行拉平。**
   - 本仓有真 SGP4、真受晒、真轨迹、真 DSO 目录、真全量星表；这些按「已达标（比原型强）」记，不为了长得像原型而退回演示形态。
