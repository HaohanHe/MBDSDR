# FZ-04 解冻申请单（2026-11-12）

**给用户看的一页纸。批不批，看每组「你会看到什么」。**

现状一句话：FZ-04 只写了「用户裁定：位置、尺寸、颜色……一律暂停」，**没有日期、没有原话、没有理由，也从未定义什么情况算解冻**。六条工单因此一直显示「阻塞」，但技术上都能做。

**怎么批**：回复「批准颜色组」「批准尺寸组」「批准浮层组」即可，可只批一组。行为组不需要批——按 FZ-04 现有条款就能开工。

## 颜色组（W87、W55、W56）

**解冻理由**：三处都只改颜色值和边框，不动任何控件的位置和大小。批了以后界面骨架完全不变，只是字更清楚、焦点看得见。
**不解冻的代价**：次要文字继续低于可读对比度；键盘用户看不见当前焦点；W61 的测试也写不了，因为它的前置就是 W55/W56。

**W87 次要文字对比度**
- 要改什么：把时间、单位、提示语这类次要文字调到能看清的颜色。
- 你会看到：这些字不再发灰；主文字和布局不变。
- 回退代价：单文件单值改动，可单笔提交回退；不涉及数据迁移。
- 档位：颜色。

**W55 键盘焦点框**
- 要改什么：给按钮、输入框加上键盘焦点外框。
- 你会看到：按 Tab 时当前控件有一圈明显的边；鼠标操作完全无变化。
- 回退代价：单文件样式回退，可单笔提交回退。
- 档位：颜色。

**W56 列表选中边框**
- 要改什么：恢复列表当前行的边框。
- 你会看到：选中的行有清晰边框，不再只靠底色区分。
- 回退代价：单文件样式回退，可单笔提交回退。
- 档位：颜色。

## 尺寸组（W49、W60）

**解冻理由**：只动局部点击范围和字号，不动整页排版。W49 解决的是触屏/高分屏点不中，W60 解决的是没有字号可调。
**不解冻的代价**：右栏节标题继续难点；视力不好的用户只能将就，没有放大选项。

**W49 节标题点击范围 24→44 像素**
- 要改什么：把右栏节标题的可点范围从 24 像素加到 44 像素。
- 你会看到：标题明显更好点中，触屏最明显；行间距可能有轻微变化。
- 回退代价：单文件数值回退，可单笔提交回退。
- 档位：尺寸。

**W60 字号档位**
- 要改什么：设置里加小/中/大三档字号，默认保持现在的大小。
- 你会看到：多一个字号选项；不选就和今天完全一样，选大字号后文字变大。
- 回退代价：revert 该笔提交即可；若保存过字号选择，需同时清掉该设置项，否则旧值仍生效。
- 档位：尺寸。

## 浮层组（W44 后半）

**解冻理由**：跨度读数和悬停 SNR 是操作反馈，不是装饰；但它们确实会在屏幕上多出字和浮层，所以单独成组，不跟行为组捆在一起。
**不解冻的代价**：调带宽、判断信号强弱只能靠猜。

**W44 跨度读数 + 悬浮 SNR**
- 要改什么：频谱上显示当前跨度；鼠标停在频谱上显示该点 SNR。
- 你会看到：频谱角落多一行跨度数字；悬停时多一个小提示。
- 回退代价：单文件移除浮层；不影响已录制数据。
- 档位：浮层。
