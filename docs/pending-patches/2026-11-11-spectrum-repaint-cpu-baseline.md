# 重测：逐帧重绘 CPU 省幅（offscreen 数字作废，以 windows 为准）

> 日期：2026-11-11；相关提交：`63a20b2c`（fix(spectrum): 重绘唯一驱动改回面板定时器）
> 测量脚本：`%TEMP%\kilo\bench_refresh_labels_win.py`（一次性，不入仓库）
> 结论：`63a20b2c` 提交说明里的 **86.7% → 10.9%（-87.4%）作废**。那是
> `QT_QPA_PLATFORM=offscreen` 下量的——该平台 `QFontDatabase.families()` 为
> **0**，文字全渲染成方框、没有字形栅格化，而重绘的大头之一正是文字。
> windows 平台（394 个字体族）实测省幅为 **-56%～-61%**，且旧实现根本喂不动
> 146 帧/s。

## 一、场景（两台一致）

- `SpectrumPanel` 1280×720，带真实形状的 FFT + 满水位瀑布；
- 146 帧/s 灌 2 s（2.4 MS/s ÷ 16384 ≈ 146 帧/s）；
- A = 旧行为：`_refresh_status_labels()` 每帧无条件 `_redraw()`；
- B = 新行为：首帧补画 + 主窗 10 Hz 节流，重绘由面板定时器驱动；
- windows 平台用 `WA_DontShowOnScreen` 不上屏，字体/字形栅格化与真机一致。

## 二、对照表（定速 146 帧/s，2 秒）

| 平台 | 字体族 | A 旧：实收帧 | A CPU 占用 | B 新：实收帧 | B CPU 占用 | 占用降幅 |
| --- | --- | --- | --- | --- | --- | --- |
| offscreen | 0 | 292 / 292 | 85.1% | 292 / 292 | 10.2% | **-88.1%** |
| windows #1 | 394 | **82 / 292** | 109.0% | 292 / 292 | 42.2% | -61.3% |
| windows #2 | 394 | **84 / 292** | 98.1% | 292 / 292 | 43.0% | -56.2% |
| windows #3 | 394 | **85 / 292** | 99.0% | 290 / 292 | 39.8% | -59.8% |
| windows #4 | 394 | **78 / 292** | 103.7% | 280 / 292 | 59.3% | -42.8% |

以 windows 为准：**A 约 98%～109%（并丢弃约 71%～73% 的帧），B 约 40%～59%
（帧基本收满），占用降幅约 -43%～-61%。** 第 4 次 B 明显偏高、定帧成本也从
25.2 ms/帧跳到 40.6 ms/帧，是测量时机器上有并发任务（其他会话在跑测试/构建）
所致——**这台机器上 B 的绝对值受负载影响大，给区间不给单点**。

## 三、每帧真实成本（定帧 292 帧、不定速）

| 平台 | A 总 CPU | A 每帧 | 说明 |
| --- | --- | --- | --- |
| offscreen | 1.703 s | 5.83 ms | 无字形栅格化，绝对值偏小 |
| windows | 7.359～11.844 s | 25.20～40.56 ms | 有字形栅格化，是 offscreen 的 4.3～7.0 倍 |

定帧 B 在 windows 下只有 0.03～0.23 s，是因为该模式下没有墙钟让面板定时器
触发重绘——它不代表「同样工作更便宜」，故不进结论。A 的定帧成本说明：若真按
146 帧/s 处理满 2 s，仅这一条通路的 CPU 就要 7.4～11.8 s。

## 四、措辞修正（后续引用请用这版）

- 原：单核占用 86.7% → 10.9%（-87.4%）。
- 新：windows + `WA_DontShowOnScreen`、146 帧/s × 2 s 下，单核占用
  **约 98%～109% → 约 40%～59%（-43%～-61%）**；更关键的是旧实现 2 s 只
  消费 78～85/292 帧（约 71%～73% 的 IQ 帧被丢弃），新实现 280～292 帧全部接住。
- offscreen 的 85.1% → 10.2% 只能作为「同平台改前/改后相对趋势」，不可
  当作真机绝对值或省幅。

复跑（两条命令分别对应两平台）：

```powershell
$env:BENCH_PLATFORM='windows'; python "$env:TEMP\kilo\bench_refresh_labels_win.py"
$env:BENCH_PLATFORM='offscreen'; python "$env:TEMP\kilo\bench_refresh_labels_win.py"
```
