# 窄屏重排方案（narrow-screen-plan）

> 状态：**部分落地**。高度批已收（§3.1）；宽度按用户 2026-11-05 裁定改用
> DPR 1.0 口径，验收线 **1344×700**（1366×768 扣边框/任务栏）。已落地：
> 频谱工具栏（§2.1.1）、卫星面板折叠（§3.1）、顶栏收窄（§2.3.1）。
> 数字来源只有一个：`python scripts/ui_narrow_breakdown.py`（只读，见 §1.0）。
> **不按 §1.0 的环境指纹复跑就不许拿这些数改代码。**

## §0 结论先说

1. **原始基线（2026-11-04，未改前）**：三处宽度溢出 + 一处高度溢出。
   - 顶栏 `topBar` 最小宽 **1625**（DPR 1.0 口径）
   - 主工具栏可用下限 **1670**（QToolBar 自报 52 是假的，见 §1.2）
   - 频谱工具栏 **1941**，1366 下频谱实际只有 **756** 宽（右栏常驻时）
   - 高度 **729**；1366×768 屏扣任务栏后可用约 **728**
2. **已落地（2026-11-05）**：顶栏 1625→**1265**（§2.3.1）、频谱 1941→**688**（§2.1.1）、
   高度 729→644→**618** / 799→659→**633**（§3.1 + §3.2）。
3. **新验收线（DPR 1.0 = 1366×768 @100%）**：可用 **1344×700**。
   当前 offscreen 指纹 **内容最小 1265×618**（宽余 79 / 高余 82）；真屏 DPR 1.5 指纹
   **内容最小 960×633**（宽/高均不退化：原 1237×659）。两指纹都过。
   窗口地板仍是 `setMinimumSize(1000, 600)`（`main_window.py:591`），口径见 §2.3.2。

> **36 与 39 的差从哪来**：主工具栏实测高 **39** = 子控件最高 `sizeHint` **31** +
> `QStyle` 上下边距 **8**。`tokens.SIZE` 里**没有 `toolbar_h` 键**，36 不是令牌值；

> **44 = 36 + 8**）。换字体或换真屏样式后这项会变，所以它必须和环境指纹一起报。

> **旧口径 `1726 / 736` 未复现**：同一脚本在 offscreen 指纹下唯一输出
> **1625 × 729**；在真屏（`windows`，DPR 1.5、行高 18）输出 **1237 × 799**。
> `1726 / 736` 在两种指纹下都复现不出来（隐藏 `topBar` 反而降到 808 宽）。
> 因此本文件**只认脚本输出**：旧值来源不明，按「指不到依据就标未核实」处理，
> **不得**拿 1726 / 736 做验收或据此改代码；另一条线对账时必须贴同一指纹的
> 脚本输出（含 §1.0 的 `env` 段）。

### §2.3.2 口径核对：960 是「内容最小」，不是「窗口最小」

`setMinimumSize(1000, 600)` 在 `desktop/main_window.py:591`，**本批没动过**。
`minimumSizeHint()` 是内容自己想多宽，会被字体/样式度量放大或缩小，**不能当窗口地板**。

**三个实测数（同一时刻，两种指纹）**

| 指纹 | `minimumWidth()` 声明值 | `width()` 实际（resize 1000 后） | `minimumSizeHint()` 内容值 |
| --- | --- | --- | --- |
| offscreen DPR 1.0 | **1000** | **1000** | 1265×618 |
| windows DPR 1.5 | **1000** | **1000** | 960×633 |

强制越界验证：两种指纹下 `resize(800, 500)` **都还是 1000×600** → 硬墙生效，960 从未成为实际窗口宽。

**1237→960（真屏 277px）逐项对账**（同一窗口、同一 DPR 1.5、同一字体）：

| 项 | 改前 | 改后 | 省 |
| --- | --- | --- | --- |
| `txCapability` 全文 → 图标 | 204 | 26 | **178** |
| `UTC: yyyy-MM-dd HH:mm:ss` → `HH:MM:SS` | 198 | 99 | **99** |
| 其余 15 个子控件（未连接/频率/采样率/GNSS/多普勒×2/发射×2/呼号标签/呼号输入/5 条分隔线） | 880 | 880 | **0** |
| 子控件合计 | 1082 | 805 | **277** |
| 布局间距 + 边距 | 155 | 155 | **0** |
| **topBar 最小宽** | **1237** | **960** | **277** |

差额 = 0（178 + 99 = 277，恰好对上；间距/边距 155 前后不变）。底坞与中央区对宽度
贡献 0（底坞只改高度；中央区隐藏 topBar 后两指纹都是 808）。

**305px 差（1265 − 960）的构成**——用「隐藏对照」判，不用猜：

| 部分 | offscreen | windows | 差 |
| --- | --- | --- | --- |
| 顶栏 `topBar` 内容最小 | 1265 | 960 | **305（全部）** |
| 中央区（隐藏 topBar 后窗口地板） | 808 | 808 | **0** |

即：305 全在顶栏，来自两个平台的字体/样式度量差（同一批标签
`频率: —` 75/55、`采样率: —` 90/70、`GNSS` 135/95、`多普勒` 104/67、
`UTC HH:MM:SS` 180/99、呼号输入 251/149、分隔线 12/3）。
布局结构没有变，是度量口径差。

**越界/挤压控件计数（脚本 §4f 输出，可复跑）**

统计口径（脚本 `_scan_overflow`，唯一口径）：
- 扫描根：`topBar` / `bottomDock` / 主工具栏 / `centralWidget` 四个；

  `sizeHint().width() > width()+2`（= 有字控件被压到小于它想要的最小宽）。

## §2.6 可折叠面板：先定「收起来还找得到」的口径

可折叠省高度（卫星页约 89/146），但**收起不等于藏起来**。施工前把可达性口径写死：

1. **标题行常驻可见**：每个 `QGroupBox` 收起后仍显示标题文字 + 指示符（`▼` 已展开、点可收起 / `▶` 已收起、点可展开），不是整块消失；
2. **标题行要写「里面有什么」**：例如「卫星参数 · 3 项」「过境预测 · 2 项」，不写「更多」这种无信息词；数量随内容变化；
3. **可点区域（按实际实现如实写）**：标题左侧的复选框指示符可点（Qt 可勾选 `QGroupBox` 原语）；
   tooltip 在收起态写「已收起，点击标题展开」。**整行可点 / 键盘 `Space` 本轮未做**，
   若需要要加事件过滤器，单列后续，不在本轮口径里假称已支持；
4. **默认态**：窄屏（<1440）默认收起，宽屏默认展开；**本轮不持久化**（见第 7 条），只在首次判定一次，避免窗口拖动来回抖动；
5. **可达性断言**（写进测试，两种指纹都跑）：收起后 **分组框仍 `isVisible() is True`**（标题行在）、**正文子控件 `isVisible() is False`**；勾选指示符后反向；**子控件一个不删**，`findChild` 仍能按属性名取到；
6. 上述省量是估算，**已落地实测为 85 / 140**（见 §3.1）；若后续再改分组框内容，
   必须用 §1.0 脚本复测并更新本表。
7. **默认态不持久化**（本轮）：窄屏默认收起、宽屏默认展开；要持久化需新增
   settings 键并经评审，不与既有键混用。

## §4 验收口径（冻结解除后第一件事按这个改）

**规则（双指纹最坏值，不许挑一个指纹交差）**：

1. 同一组断言必须在**两种指纹**下各跑一次：`offscreen` 与真屏 `windows`；
2. **DPR 1.0（offscreen）**：宽 ≤ **1344** 且 高 ≤ **700**（1366×768 @100%
   扣边框/任务栏后的可用区）；**真屏 DPR 1.5（windows）**：不得比
   2026-11-05 基线更差（宽 ≤1237、高 ≤659；实测 960×633）；
3. 每次测量输出必须带 `env` 段（platform / DPR / 逻辑 DPI / 字体与行高 /
   style），**缺一段视为无效**；
4. 任一指纹失败即不合格，不得用另一指纹的通过来抵。

```python
import json, os, subprocess, sys

LIMITS = {
    "offscreen": (1344, 700),   # DPR 1.0：1366×768 @100% 扣边框/任务栏
    "windows":   (1237, 659),   # 真屏 DPR 1.5：不得比基线更差
}
ENV_KEYS = ("qt_platform", "device_pixel_ratio", "logical_dpi",
            "font_family", "font_point_size", "font_line_height", "style")

def _measure(platform):
    env = dict(os.environ, QT_QPA_PLATFORM=platform)
    out = subprocess.run(
        [sys.executable, "scripts/ui_narrow_breakdown.py", "--json"],
        capture_output=True, text=True, env=env, check=True).stdout
    data = json.loads(out[out.index("{"):])
    missing = [k for k in ENV_KEYS if k not in data.get("env", {})]
    assert not missing, f"[{platform}] env 缺 {missing}，测量无效"
    return data["summary"]

@pytest.mark.parametrize("platform", ["offscreen", "windows"])
def test_narrow_screen_is_fully_usable(platform):
    s = _measure(platform)
    # 口径：window_minimumSizeHint = 内容最小；window_minimumWidth = 声明硬墙。
    # 两者都断言，别把内容最小当窗口地板（见 §2.3.2）。
    w, h = s["window_minimumSizeHint"]
    limit_w, limit_h = LIMITS[platform]
    assert w <= limit_w, f"[{platform}] 内容最小宽 {w} > {limit_w}"
    assert h <= limit_h, f"[{platform}] 内容最小高 {h} > {limit_h}"
    assert s["window_minimumWidth"] == [1000, 600], (
        f"[{platform}] 声明最小被改动：{s['window_minimumWidth']}"
        f"（应先答「为什么改、依据是什么、有没有破坏 1000 那条测试」）")
    assert s["topBar_width"] <= w, f"[{platform}] topBar {s['topBar_width']}"
    # 注意：summary 里的 mainToolBar_width 是「内容合计」（1344 下 1575），
    # 不是窗口最小宽地板——Qt 会把右端 6 个控件收进 » 菜单（1 次点击可达，
    # 见 §2.3.1）。窗口地板由 topBar / 中央区决定，故此处不断言它 ≤ limit_w。
    assert s["spectrum_width"] <= limit_w, (
        f"[{platform}] 频谱工具栏 {s['spectrum_width']}")

@pytest.mark.parametrize("platform", ["offscreen", "windows"])
def test_no_text_squeezed_at_target_width(platform):
    """目标 1344×700 下顶栏/底坞不得有控件被压到小于 sizeHint（§2.3.2）。"""
    s = _measure(platform)
    over = s["caliber"]["overflow_at_1344x700"]
    top_squeezed = [r for r in over["squeezed"]
                    if r.startswith("topBar:") and "statusValue" in r]
    assert not top_squeezed, f"[{platform}] 顶栏状态标签被压：{top_squeezed}"
    assert over["clipped_count"] <= 1, (
        f"[{platform}] 越界控件 {over['clipped_count']} > 1（唯一允许项是 "
        f"ControlPanel 自己的滚动视口）")
```
