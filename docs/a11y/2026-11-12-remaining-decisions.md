## 单独一项：原 T3-26 发送按钮（4.49，差 0.01）

`ai_panel.py:518-523`：`accent_warm #8B7355` 底 + 白字，**9pt / 500**。
9pt 粗体也不到 WCAG 大字号门槛（≥14pt 粗体或 ≥18pt 正文），所以没有
3:1 豁免，必须按 4.5 算——**4.49 差 0.01 属实**。两条路：

- **路 1（改字色）**：白字 → `bg_dark #000000`，**4.68**。
  代价：发送按钮的字从白变黑，和旁边深底白字的按钮不是一套；暖棕底压黑字偏“印刷感”。
- **路 2（改底色）**：底 `#8B7355` → 既有 `accent_warm_hover #7A6449`，白字 **5.61**。
  代价：**平时就是 hover 的颜色**，hover 的反馈消失（要另找 hover 值→又回到新增色值）。
- 不改：唯一差 0.01 的正文点，留着就是一个“已知不合规”的例外，以后每次审计都会再翻出来。
