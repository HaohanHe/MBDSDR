---

**今晚新增四条执行纪律（同日生效，命中即返工，不按个人偏好裁量）：**

1. **改完会被 import 的模块，必须跑一次真实 import**：以 `python -c "import desktop.<module>"`（或等价入口）为准，单测绿不算。今晚两次别线测试因此被炸：`settings_panel.py` 缺 `QShortcut`、`new_spacetime_panel._apply_passes_filter` 缺失。
2. **`--no-verify` 禁用**：需要绕过钩子必须先报批，并在提交说明里写明批准人/批次。
3. **私有 index 挡不住父提交前进**：`read-tree` 与 `commit` 之间必须复核 `git rev-parse HEAD`；与 index 建立时不一致就重建 index 再提交（今晚同一文件连撞三次）。
4. **抽取方法与调用点必须同批落盘**；若确实要分批，只能「先加新方法、再改调用点」，不许反过来。**⑯ 第六例（今晚）**：`settings_panel.py:1126` 把 `_append_storage_tools` 抽走、调用点未并，结果不是「自己的测试红」，而是**别线用例在 setup 阶段 3 个 ERROR、MainWindow 构造直接断掉**——影响面是整棵树，比「文件里引用不存在的方法」更严重。
