# 可访问性与输入效率缺口调研（只读）

- 调研日期：2026-11-11
- 基线：`6ba5c175`
- 范围：`desktop/` 共 62 个 Python 模块；不含 `cpp/`、后端与打包脚本
- 方法：源码静态审计（AST 统计 + 逐文件阅读），未启动 GUI
- 口径声明：
  - tooltip 覆盖率为**构造点静态近似**（259 个命名交互控件中 122 个被赋过 `setToolTip`），不是运行时控件枚举；运行时控件数更大（`themes.py:164` 记录主窗口仅 `QToolButton` 就有 138 个）。
  - 对比度按 WCAG 2.x 公式由 `tokens.py` 色值实算；项目自身门槛见 `tests/test_ui_contrast.py`（正文 4.5:1、禁用态 1.5:1）。
  - DPI/字体截断类结论标注「需实测」的，必须用 DPI 1.0 / 1.5 / 2.0 三档截图复核后才能定级。

## 3. 缺口明细

### 3.1 命令面板与入口可发现性

**G-01 顶栏无命令面板入口** — P1 / S
- 证据：`main_window.py:1542-1549`（仅「帮助」菜单 + Ctrl+K）；`main_window.py:3936-3957`（顶栏只有「详细」「⧉」、UTC）。
- 现象：唯一全局检索入口藏在二级菜单与一个快捷键里。
- 影响：新用户不知道 Ctrl+K，等于没有命令面板；与 `ac87f7b9` 的投入不匹配。
- 修复：顶栏「详细」左侧加一个放大镜按钮，复用 `_show_command_palette`。

**G-02 命令面板回车不执行** — P1 / S
- 证据：`command_palette.py:298-314`（只有 `textChanged` 连接，无 `returnPressed`）；`:371-372`（依赖列表 `itemActivated`）。
- 现象：打开后焦点在搜索框，输入完按 Enter 无反应；必须再按 Tab 把焦点移到列表，再按 Enter。
- 影响：违反命令面板「输入即执行」的基本预期，键盘效率损失一步且容易被误判为卡死。
- 修复：搜索框 `returnPressed` 直接执行 `currentRow()` 条目；同时支持 Down 从搜索框进入列表。

**G-03 执行失败提示被隐藏** — P1 / S
- 证据：`command_palette.py:354-358`（先 `self.hide()`，失败后只写 `reason_label`）。
- 现象：条目不可用/执行抛错时，面板已关闭，用户看不到任何原因。
- 影响：用户以为命令生效，实际无动作；与项目「失败必须显式说明」原则冲突。
- 修复：执行前先判定 `runnable`；失败不关闭面板并在列表下方常驻原因，或写入状态栏 + 日志。

**G-04 设置项不可被检索** — P1 / M
- 证据：`settings_panel.py:617-658`（7 个可折叠分组，无 QLineEdit/过滤）；`command_palette.py:153-171`（页签索引只到「设置」整页）；`:246-272`（仅子串匹配）。
- 现象：想改「主题/语言/录音目录」只能滚到设置节再逐组找；命令面板搜「录音目录」搜不到具体项。
- 影响：设置项越多，查找成本线性上升；这是当前最慢的常用操作。
- 修复：把 `EXPOSED_ITEMS` 展开为二级命令（`设置 → 通用 → 操作员呼号`），执行时展开对应分组并高亮；设置页顶部加过滤框。

**G-05 搜索能力弱** — P2 / M
- 证据：`command_palette.py:238-243`（索引构建）、`:246-272`（`_relevance` 仅子串）、无「最近使用」。
- 现象：不支持拼音首字母、模糊匹配、多关键词；常用命令不会上浮。
- 影响：中文用户输入成本高；重复操作每次都要重新拼写。

### 3.2 键盘可达性与焦点

**G-06 无「聚焦频谱」全局快捷键** — P1 / S
- 证据：`spectrum_widget.py:3159`（`StrongFocus`）；`:3538-3569`（方向键/滤波/模式键全部是控件局部按键）；`shortcuts.py:100-125` 的频谱键注明「频谱获焦时生效」；菜单（`main_window.py:1358-1549`）无此动作。
- 现象：所有高频频谱键（方向键、A/N/F/W/C、滤窄/滤宽）都以前置条件「频谱已有焦点」为前提，但没有一键把焦点送进频谱。
- 影响：键盘用户每次都要先 Tab 一长串或走命令面板，局部快捷键形同虚设。
- 修复：新增全局动作「聚焦频谱」（如 Ctrl+Shift+F 或直接 `Esc` 回频谱），执行 `plot.setFocus()`。

**G-07 按钮/复选框无可见焦点样式** — P1 / L
- 证据：`themes.py:559-598`（QPushButton 只有 hover/pressed/disabled）、`:302-330`（QToolButton 同）、`:656-662`（仅状态类）、`:685`（QLineEdit 有 `:focus`）、`:771`（QSpinBox 有 `:focus`）。
- 现象：全仓 QSS 只给输入框与数值框定义了 `:focus`，按钮、复选框、单选框、下拉框没有焦点态；QSS 上色后 Qt 原生虚线焦点框通常不再绘制。
- 影响：纯键盘用户无法判断「我现在在哪个按钮上」，这是 WCAG 2.4.7 失败项，也是键盘操作的最大障碍。
- 修复：在主题 QSS 中统一增加 `QPushButton:focus/QToolButton:focus/QCheckBox:focus/QComboBox:focus { border: 2px solid <accent>; }`，并在 5 个主题中各自验证对比度 ≥3:1。

**G-08 列表焦点指示被移除** — P1 / S
- 证据：`themes.py:382-402`（`QListView { outline: none; }`，选中态只用底色）。
- 现象：列表/树获得焦点与失去焦点视觉相同，键盘上下移动时看不出「当前活动列表」。
- 影响：多面板并存时键盘用户会误操作到另一个列表。
- 修复：为 `:focus` 的列表加 1px 强调色内描边，或恢复默认 outline。

**G-09 Tab 顺序覆盖范围与实际不符** — P1 / S
- 证据：`main_window.py:1736-1751`（唯一一条 `setTabOrder` 链）；`:1617-1628`（`theme_combo`/`lang_combo` 创建后未 `toolbar.addWidget`，属不可见悬空控件却进入链）；`:2101-2104`（默认专注模式隐藏整个 QToolBar）。
- 现象：显式链只串了 13 个工具栏控件；默认启动时整条链隐藏，Tab 实际回落到创建顺序。链中还夹了两个界面上不存在的下拉框。
- 影响：注释宣称的「按视觉从左到右、链尾进入中央三栏」在默认状态下不成立；Tab 会跳序。
- 修复：按「顶栏 → 左栏 → 中栏 → 右栏」重排；从链中删除未挂载控件；对左右栏各加一次显式 `setTabOrder`。

**G-10 频率按位编辑仅鼠标** — P2 / S
- 证据：`freq_display.py:175-193`（`mousePressEvent` 按位加减）；无 `keyPressEvent`，无 `setFocusPolicy`。
- 现象：大号频率数字只能点击/滚轮逐位改，键盘无法进入。
- 影响：触摸板/键盘用户只能改用 `freq_input` 文本框；两套入口行为不一致。
- 修复：给 `FreqDisplay` 加 `StrongFocus` + 左右键选位、上下键加减、数字键直填。

**G-11 折叠分组键盘不可展开** — P2 / S
- 证据：`sat_track_panel.py:92-120`（`_CollapsibleGroupBox` 仅 `mousePressEvent`；QSS 把 indicator 设为 0×0，注释明确键盘按不到）。
- 现象：「实时状态」「仰角」等分组只能鼠标点标题展开。
- 影响：键盘用户看不到组内信息；右栏 `RightSection` 用 QToolButton 可键盘切换，两个折叠组件行为不一致。
- 修复：复用 `RightSection` 的实现，或给标题加 `StrongFocus` + Space/Enter 切换。

**G-12 错误补救链接仅鼠标可点** — P2 / S
- 证据：`error_remedy.py:198-200`（`setTextInteractionFlags(Qt.LinksAccessibleByMouse)`）。
- 现象：错误提示里的「怎么修」链接键盘无法聚焦/激活。
- 影响：恰好在出错时阻断键盘用户的恢复路径。
- 修复：改为 `LinksAccessibleByKeyboard | LinksAccessibleByMouse`。

**G-13 滑杆无数字输入** — P2 / M
- 证据：`control_panel.py:614-626`（增益）、`:525`（音量）、`gain_panel.py:59`（LNA/Mixer/VGA）。
- 现象：10 个 QSlider 均无配套 QSpinBox；键盘只能方向键逐步调，无法输入目标 dB。
- 影响：校准/复现实验时无法精确设定；键盘操作步数多。
- 修复：滑杆右侧数值标签改为可编辑 `QSpinBox`，双向绑定。

**G-14 卫星关键动作无快捷键** — P2 / S
- 证据：`shortcuts.py:69-72`（`tools.sat_start`/`sat_stop`/`sat_tle` 的 key 均为 `None`，备注「低频/避免误触」）。
- 现象：开始/停止跟踪必须走菜单或右栏折叠区。
- 影响：过境窗口只有几分钟，鼠标 4 步在追星场景下偏慢。
- 修复：至少给「开始/停止跟踪」配一个组合键，并保留确认。

**G-15 屏幕阅读器信息缺失** — P2 / S
- 证据：全仓仅 3 处 `setAccessibleName/Description`；`main_window.py:3945-3951` 的「⧉」按钮只有 tooltip，无可访问名。
- 现象：图标按钮对读屏软件只暴露符号本身。
- 影响：读屏用户无法理解按钮用途。
- 修复：为所有纯图标按钮补 `setAccessibleName`，与 tooltip 同源。

### 3.3 菜单与快捷键结构

**G-16 模式切换不在菜单** — P2 / S
- 证据：`main_window.py:1358-1549` 只有文件/视图/工具/帮助四个菜单，无「模式」项；模式只在 `control_panel.py:389` 与频谱局部键。
- 现象：用户按常规「菜单里找功能」的路径找不到解调模式。
- 影响：可发现性差；且菜单无项意味着命令面板只能索引到「控制」页签。
- 修复：在「工具」下加「解调模式」子菜单，与 `MODE_*` 表同源生成。

**G-17 设置与导出无菜单入口** — P1 / M
- 证据：同 G-16；`settings_panel.py:1327-1331`（导入/导出在设置页底部）；`bookmark_panel.py:128-130`（书签 CSV）；`satellite_image_panel.py:131`（图像 PNG）。
- 现象：设置、导出都埋在右栏深处，没有「文件 → 导出」或「编辑 → 设置」。
- 影响：这是「找设置项」和「导出结果」步数长的根因。
- 修复：新增「文件 → 导出」聚合菜单与「工具 → 设置」直达项。

**G-18 快捷键表存在 11 个空键** — P2 / S
- 证据：`shortcuts.py` 共 44 条，`key=None` 11 条：`view.reset_position`、`tools.gnss_disconnect`、`tools.sat_start`、`tools.sat_stop`、`tools.sat_tle`、`help.quick_start`、`help.catalog`、`help.shortcuts`、`panel.capability_matrix`、`panel.reset_layout`、`layout.delete`。
- 现象：快捷键一览里近四分之一显示「无快捷键」。
- 影响：面板看起来「功能很多但都不能按」。
- 修复：按使用频率补键，或把「无快捷键」改为「可从命令面板执行」并给出可点击入口。

### 3.4 鼠标与手势

**G-19 全仓无中键交互** — P2 / M
- 证据：`MiddleButton`/`MidButton` 在 `desktop/` 0 命中。
- 现象：中键拖动平移/中键点击设为中心频率等常见 SDR 交互缺失。
- 影响：频谱/地图只能左键拖动，误触即改频率，缺少「安全平移」手段。
- 修复：频谱与地图补中键拖动平移，不改调谐。

**G-20 右键菜单仅频谱有** — P2 / M
- 证据：`spectrum_widget.py:3637-3649`（右键删除 VFO）；天空/地图/卫星列表/书签无 `contextMenuEvent`。
- 现象：卫星「跟踪/居中/复制名称」、地图「设为中心/复制坐标」、书签「编辑/删除」都只能去别处找按钮。
- 影响：高频上下文操作缺少就近入口。
- 修复：为天空、地图、卫星列表补右键菜单，并确保菜单项可键盘触发。

**G-21 触控板捏合可能不生效（需实测）** — P1 / M
- 证据：`touch_helpers.py:154-163` 只处理 `QPinchGesture`/`QPanGesture` 与 Touch 事件；全仓无 `QNativeGestureEvent` 处理（仅在注释里出现）。
- 现象：Windows 高精度触控板通常投递 NativeGesture 或转成滚轮，未必产生 QPinchGesture。
- 影响：`PinchZoomMixin` 在触控板上可能完全无反应，用户以为功能坏了。
- 修复：实现 `event()` 中 `QEvent.NativeGesture` 分支，映射到同一 `pinch_scale_changed`；先在 Windows 触控板实测确认现状。

**G-22 天空/地图无法键盘选点** — P2 / L
- 证据：`osm_map.py:1343-1368`（仅方向键平移与 +/- 缩放，无键盘设点）；`rf_sky_view.py:3994-4040`（仅 Esc/A/C）；天体/卫星点选依赖 `object_clicked` 鼠标坐标。
- 现象：地图选观测站、天空点选天体只能鼠标。
- 影响：键盘用户无法完成「地图设点」这一配置步骤。
- 修复：地图增加「回车在中心设点」；天空增加「Tab 循环可搜索天体 + 回车选中」，复用已有搜索索引。

### 3.5 高 DPI 与字体缩放

**G-23 无用户可调字号** — P1 / M
- 证据：`themes.py:138-155`（全局 `setPointSize(10)`）；`config_schema.py` 的 `GROUP_ORDER` 与设置项中无字体/缩放项。
- 现象：只能跟随系统 DPI，应用内不能放大字号。
- 影响：低视力用户无法在不改系统缩放的情况下放大界面；与「高对比主题」的无障碍投入不配套。
- 修复：新增 `ui_font_scale` 设置（0.85–1.5），启动时按比例调整全局字体与关键固定高度。

**G-24 硬编码字号与固定尺寸偏多，仅少量省略** — P1 / M（截断需实测）
- 证据：全仓 71 处 `font-size: Npt`；24 处 `setFixedWidth/Height/Size`；165 处 `setMinimum/MaximumWidth/Height`；仅 6 处 `elidedText`（`main_window.py:3841-3879`、`control_panel.py:1091-1103`、`module_panel.py:79-86`、`adsb_map_panel.py:356-369` 等）。
- 现象：大量文本容器宽度/高度写死，长文案只有少数位置做省略。
- 影响：DPI 1.5/2.0 或系统字体放大时，状态栏、页签、按钮文字存在被裁切风险（需实测逐项确认）。
- 修复：高频截断点改用 `QFontMetrics.elidedText`；固定高度改为 `minimumHeight`；补 DPI 三档截图回归。

**G-25 关键固定高度偏紧** — P2 / S（需实测）
- 证据：`tokens.py:318-319`（`topbar_h=56`、`bottomdock_h=48`）；`main_window.py:3909`、`:4037`、`:2039`（右栏导航 22px + 9pt）。
- 现象：顶栏/底坞/右栏导航高度写死，字号放大后垂直余量不足。
- 影响：文字上下被裁或按钮被压扁。
- 修复：改为 `max(base, fontMetrics.height()+padding)` 动态计算。

**G-26 默认主题强调色在 bg 上未达 3:1** — P2 / S

- 影响：浅色主题下选中框、图标边界辨识度不足。
- 修复：按 `bg` 而不是 `card` 重算并压暗一档，或规定强调色只出现在 `card` 上。

**G-27 figma 主题边框低于项目自定门槛** — P2 / S

- 现象：Figma 主题的输入框/卡片边界最弱。
- 影响：深色低对比环境下控件边界难辨。
- 修复：将 `#404040` 提到约 `#474747`（对 card ≥1.5），并补进对比度测试矩阵。

**G-28 CLI 主题枚举与设置面板不一致** — P2 / S

- 现象：`--theme dark_car` / `--theme figma` 会被 argparse 拒绝。
- 影响：自动化/截图脚本无法指定实际在用的主题。
- 修复：choices 直接由 `THEMES.keys()` 生成，避免第二份清单。

## 5. 未核实 / 需实测项

以下结论只做了静态判定，定级前必须实机复核：

1. **DPI 1.0 / 1.5 / 2.0 文字截断**：需在三种缩放下截图，逐项确认 G-24 / G-25 的实际截断位置；静态只能证明「固定高度 + 硬编码字号」存在风险。
2. **Windows 触控板捏合**：需在真实 Precision Touchpad 上确认 Qt 是否投递 `QPinchGesture`；若只投递 `NativeGesture`，G-21 从「可能」升级为「确定失效」。
3. **QSS 是否抑制原生焦点虚线**：需在 Windows 原生样式下截图确认按钮焦点态；若原生焦点框仍在，G-07 可降为 P2。
4. **屏幕阅读器**：`setAccessibleName` 只有 3 处是静态事实，但实际朗读效果依赖 NVDA/Narrator，未实测。
5. 本报告未启动 GUI、未修改任何产品代码；所有 `path:line` 均对基线 `6ba5c175` 有效。
