## 0. 三十秒用法

1. 先搜 §1「禁止 / 待收敛」列 —— 命中就改，不必再论证。
2. 新概念：先给出「标准写法 + 字面量多数派（处数 + `path:line`）+ 例外」，再落字。
3. 注释、docstring 里的旧词不算缺陷，但**也不能拿一处注释当标准**。反面案例：「星相仪」只出现在 1 处窗口标题 + 3 行注释，曾被当成「用户口径」，反过来要求 78 处「星象仪」改口（详见 `docs/research/2026-11-11-gap-copy.md` §2.0）。

## 2. 单位口径

| 量 | 写法 | 示例 | 现状 |
|---|---|---|---|
| 采样率 | `MS/s` | `2.048 MS/s` | 52 行在用 |
| 频率 / 带宽 | `MHz` | `145.500 MHz` | 在用 |
| 符号率 | `MBd` | `1200 Bd` / `0.0012 MBd` | 当前 0 处（尚无符号率读数）；新增时按此列，不自造 `baud/s` |
| 吞吐 | `Msps` | `2.4 Msps` | 当前 0 处 |

规则：同一读数不混用两种单位；`MS/s` 与 `MHz` 不互换（前者是采样，后者是射频）。

## 3. 立新词的最小流程

1. 在 PR 描述里写一行四元组：`<概念> / <标准写法> / <字面量处数 + path:line> / <保留的例外>`。
2. 若标准写法与现有最大簇不一致，必须写理由（词义、用户对象、或与相邻概念成对）。
3. 落字后回来本表加一行；不回来加行 = 下一个人还会再造一个词。

## 4. 复算方法

1. 初筛（含注释，需人工剔除）：

```powershell
git grep -n "站址" -- 'desktop/*.py'
```

2. 本表数字的取法：用 AST 只取 `ast.Constant` 字符串，排除模块/类/函数 docstring 与 `logger.*` / `print(...)` 实参，再按词计数。
3. 计数会随其他线落地漂移；引用本表时注明快照日期，改动前用第 1 步复核「例外」列是否还在。
